## एजेंट स्किल्स

अपने पसंदीदा AI कोडिंग एजेंट को Tendril के आधिकारिक इंजीनियरिंग और डीबगिंग स्किल्स से विस्तार दें।

### तुरंत शुरू करें

यूनिवर्सल स्किल्स इंस्टॉलर से किसी भी समर्थित एजेंट के लिए Tendril स्किल्स इंस्टॉल करें:

```bash
npx skills add ivy-interactive/ivy-tendril
```

या कोई एक विशिष्ट स्किल इंस्टॉल करें:

```bash
npx skills add ivy-interactive/ivy-tendril --skill tendril-debug-plan
```

### समर्थित टूल और परिवेश

<details>
<summary><strong>Visual Studio Code (GitHub Copilot और एक्सटेंशन)</strong></summary>

VS Code में GitHub Copilot के लिए स्किल्स इंस्टॉल करें:

```bash
npx skills add ivy-interactive/ivy-tendril --agent github-copilot
```

ग्लोबल इंस्टॉल (सभी वर्कस्पेस में):

```bash
npx skills add ivy-interactive/ivy-tendril --agent github-copilot -g
```

या स्किल्स को सीधे `.agents/skills/` या `.github/skills/` (प्रोजेक्ट स्तर) या `~/.copilot/skills/` (ग्लोबल) में कॉपी करें।

इंस्टॉल होने के बाद स्किल्स GitHub Copilot Chat में `/skills` मेन्यू के अंतर्गत दिखते हैं और स्लैश कमांड के रूप में सीधे चलाए जा सकते हैं (जैसे `/tendril-debug-plan`, `/tendril-debug-job`, `/tendril-review`, `/tendrillable`)।

VS Code के लिए तीसरे पक्ष के एजेंट एक्सटेंशन:
- Cline: `npx skills add ivy-interactive/ivy-tendril --agent cline`
- Continue: `npx skills add ivy-interactive/ivy-tendril --agent continue`
- Roo Code: `npx skills add ivy-interactive/ivy-tendril --agent roo`

एडिटर के साथ पूर्ण एकीकरण के लिए आधिकारिक [Ivy Tendril VS Code एक्सटेंशन](https://marketplace.visualstudio.com/items?itemName=ivy-interactive.ivy-tendril) इंस्टॉल करें — इससे एम्बेडेड योजना डैशबोर्ड, वर्कट्री नेविगेशन और लाइव निष्पादन निगरानी मिलती है।

विस्तृत कॉन्फ़िगरेशन विकल्पों के लिए [VS Code सेटअप गाइड](../vscode-setup.md) देखें।

## इंस्टॉल

स्टैंडअलोन डेस्कटॉप इंस्टॉलर (`.pkg`, `.AppImage`, `.exe`) सीधे [GitHub Releases](https://github.com/Ivy-Interactive/Ivy-Tendril/releases/latest) से डाउनलोड करें, या नीचे दी गई त्वरित इंस्टॉल कमांड में से कोई एक चलाएँ:

**macOS / Linux:**
```bash
curl -sSf https://cdn.ivy.app/install-tendril.sh | sh
```

**Windows:**
```powershell
irm https://cdn.ivy.app/install-tendril.ps1 | iex
```

### चलाना

Tendril एक डेस्कटॉप ऐप्लिकेशन है, लेकिन वही इंस्टॉलेशन एक CLI भी है। ये दो अलग बाइनरी हैं:
`tendril-app` डेस्कटॉप ऐप है, और `tendril` CLI तथा सर्वर है।

डेस्कटॉप ऐप्लिकेशन शुरू करने के लिए अपने ऐप्लिकेशन मेन्यू से **Tendril** खोलें (या `tendril-app`
बाइनरी सीधे चलाएँ)।

डेमॉन को बिना डेस्कटॉप UI के चलाएँ — HTTP और WebSocket API:
```bash
tendril run
```

`tendril run` पहले पोर्ट जाँचता है और डेटाबेस माइग्रेट करता है, फिर `127.0.0.1:5010` पर सेवा देता है।
इसे बदलने के लिए `--port` / `--host` का उपयोग करें, और यदि आपको बिना पूर्व-जाँच वाला सादा लिसनर चाहिए तो
`tendril serve` चलाएँ (`--tls-cert` / `--tls-key` भी यही कमांड लेती है)।

बाकी सब कुछ सबकमांड है — `tendril --help` सभी की सूची देता है, और `tendril doctor` इंस्टॉलेशन की स्थिति
बताता है (कोई `[FAIL]` न हो तो एग्ज़िट कोड 0, अन्यथा 1 — इसलिए इसे स्क्रिप्ट में गेट के रूप में उपयोग किया जा सकता है)।

## 🚀 शुरुआत करें

### आवश्यकताएँ
- [Rust](https://rustup.rs/) (edition 2021)
- [Node.js](https://nodejs.org/) (v22+) और [pnpm](https://pnpm.io/) (v11+)
- [Vite+](https://viteplus.dev/) (`vp`)
- GitHub CLI (`gh`)

### तुरंत शुरू करें

1. **डिपेंडेंसी इंस्टॉल करें**:
   ```bash
   pnpm install
   ```

2. **कंपोनेंट और UI लाइब्रेरी बनाएँ**:
   ```bash
   pnpm --filter @ivy-interactive/components build
   ```

3. **Storybook चलाएँ**:
   ```bash
   pnpm dev:storybook
   ```

4. **डेस्कटॉप ऐप बनाएँ और चलाएँ**:
   ```bash
   pnpm dev:app
   ```

5. **बैकएंड क्रेट बनाएँ**:
   ```bash
   cargo build --workspace
   ```

6. **टेस्ट चलाएँ**:
   ```bash
   # वेब और कंपोनेंट टेस्ट
   pnpm test

   # Rust टेस्ट
   cargo test --workspace
   ```

### विज़ुअल और स्क्रीनशॉट परीक्षण

स्क्रीनशॉट सत्यापन और Storybook विज़ुअल टेस्ट स्थानीय रूप से चलाने के लिए:

```bash
pnpm install
pnpm run install:playwright:deps
```
