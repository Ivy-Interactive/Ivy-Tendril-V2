# CLI

Tendrils kommandoradsgränssnitt tillhandahåller kommandon för att hantera planer, projekt, databaser och daemon-processer direkt från din terminal.

- [CLI-översikt](00_Overview.md) — globala alternativ, miljövariabler och viktiga felsökningskommandon.
- [plan](01_Plan.md) — skapa, lista, uppdatera och validera planer, worktrees, revisioner och verifieringar.
- [project](02_Project.md) — konfigurera projekt, arkiv, byggberoenden, granskningsåtgärder, MCP-servrar och färdigheter.
- [verification](03_Verification.md) — definiera och hantera återanvändbara globala verifieringskontroller.
- [Databas](04_Database.md) — schemaversioner, migreringar, databasåterställningar, integritetskontroller och vacuum.
- [Övriga kommandon](05_Other.md) — promptware-exekvering, jobbspårning, chattsessioner, tjänsteregistrering och verktyg.
- [config](06_Config.md) — läs och uppdatera toppnivåinställningar lagrade i `config.yaml`.
- [vault](07_Vault.md) — anslut teamvalv, upptäck delade arkiv och importera eller publicera projekt.
