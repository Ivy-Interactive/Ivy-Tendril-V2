# Avancerat

Utforska avancerad konfiguration, daemon-automatisering och CLI-verktyg för Ivy Tendril.

Det här avsnittet täcker kommandoradsgränssnittet, REST-daemonslutpunkter för programmatisk körning av planer och jobb samt Model Context Protocol-servrar (MCP) som exponeras för kodningsagenter.

- [CLI-referens](01_CLI/_Index.md) — fullständig referens för `tendril`-kommandoradsgränssnittet, underkommandon och flaggor.
- [REST-API](02_REST.md) — daemonslutpunkter för programmatisk plankörning, jobbhantering, inkorgsinlämningar och hälsokontroller.
- [MCP-server](03_MCP.md) — verktyg och resurser som exponeras för AI-kodningsagenter som Claude Code.
