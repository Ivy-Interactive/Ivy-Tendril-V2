# Integrationer

Anslut Tendril till externa verktyg och tjänster för att effektivisera ditt utvecklingsarbetsflöde och automatisera [planexekvering](../02_Concepts/01_Plans.md).

- [GitHub](01_Github.md) — ärendeimport, automatiskt skapande av pull requests och synkronisering av PR-status med [GitHub](https://github.com).
- [Jam.dev](02_JamDev.md) — automatiserat skapande av planer från felrapporter via [Jam.dev](https://jam.dev):s inkorgs-API-webhook.
- [OpenClaw](03_OpenClaw.md) — filbaserad planinläsning från externa verktyg som OpenClaw via Tendrils inkorgsmapp.
