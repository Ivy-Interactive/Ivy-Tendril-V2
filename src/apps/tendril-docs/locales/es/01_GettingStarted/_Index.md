# Primeros pasos

Seis páginas, en orden de lectura. Las dos primeras ponen Tendril en marcha; las dos siguientes hacen que funcione
de forma _desatendida_ en tu propio repositorio, que es donde reside el verdadero valor.

- [Introducción](01_Introduction.md) — qué es Tendril, cómo está estructurado y por qué funciona
  de esta manera.
- [Instalación](02_Installation.md) — requisitos previos, compilación desde el código fuente y dónde
  se encuentra la configuración.
- [Incorporación de una base de código](03_Onboarding.md) — lista de comprobación del equipo y del repositorio
  a revisar antes de tu primer plan real.
- [Tutorial](04_Tutorial.md) — un ciclo completo: registrar un proyecto, crear un plan, ejecutarlo, revisar
  el diff y abrir un pull request.
- [Obtener ayuda](05_GettingHelp.md) — Discord, problemas en GitHub y qué adjuntar a un informe de error.
- [Solución de problemas](06_Troubleshooting.md) — síntomas y soluciones, por área.

Cuando hayas terminado estas páginas, [Conceptos](../02_Concepts/_Index.md) explica el modelo subyacente:
[planes](../02_Concepts/01_Plans.md), [promptwares](../02_Concepts/02_Promptwares.md) y el
[ciclo de vida de los trabajos](../02_Concepts/03_Lifecycle.md).
