# Integraciones

Conecte Tendril con herramientas y servicios externos para optimizar su flujo de trabajo de desarrollo y automatizar la [ejecución de planes](../02_Concepts/01_Plans.md).

- [GitHub](01_Github.md) — importación de issues, creación automática de pull requests y sincronización del estado de PRs con [GitHub](https://github.com).
- [Jam.dev](02_JamDev.md) — creación automatizada de planes a partir de informes de errores mediante el webhook de la API de bandeja de entrada de [Jam.dev](https://jam.dev).
- [OpenClaw](03_OpenClaw.md) — ingesta de planes basada en archivos desde herramientas externas como OpenClaw a través de la carpeta de depósito Inbox de Tendril.
