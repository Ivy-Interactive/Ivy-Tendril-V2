# CLI

La interfaz de línea de comandos de Tendril proporciona comandos para gestionar planes, proyectos, bases de datos y procesos del demonio directamente desde su terminal.

- [Descripción general de la CLI](00_Overview.md) — opciones globales, variables de entorno y comandos esenciales para la solución de problemas.
- [plan](01_Plan.md) — crear, listar, actualizar y validar planes, worktrees, revisiones y verificaciones.
- [project](02_Project.md) — configurar proyectos, repositorios, dependencias de compilación, acciones de revisión, servidores MCP y habilidades.
- [verification](03_Verification.md) — definir y gestionar comprobaciones globales y reutilizables de verificación.
- [Base de datos](04_Database.md) — versiones de esquema, migraciones, reinicios de base de datos, comprobaciones de integridad y vacuum.
- [Otros comandos](05_Other.md) — ejecución de promptware, seguimiento de trabajos, sesiones de chat, registro de servicios y utilidades.
- [config](06_Config.md) — leer y actualizar las configuraciones de nivel superior almacenadas en `config.yaml`.
- [vault](07_Vault.md) — conectar vaults de equipo, descubrir repositorios compartidos e importar o publicar proyectos.
