- [API REST](02_REST.md) — endpoints del demonio para la ejecución programática de planes, gestión de trabajos, envíos a la bandeja de entrada y comprobaciones de estado.
- [Servidor MCP](03_MCP.md) — herramientas y recursos expuestos a agentes de programación con IA como Claude Code.
