# Pull Requests

Die Pull-Requests-Ansicht bietet eine zentrale Übersicht über alle aus Plänen erzeugten GitHub-PRs.

## Funktionen

- **Hintergrund-Synchronisation**: Fragt den Status von CI-Läufen, Reviews und Merges regelmäßig über `gh` ab.
- **Kostenmetriken**: Zeigt die gesamten Ausführungskosten für den zugehörigen Plan an.
- **Folge-Pläne**: Erstellen Sie mit einem Klick Folge-Pläne für Nacharbeiten oder gefundene Regressionen.
