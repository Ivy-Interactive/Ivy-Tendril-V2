# Review

Die Review-Ansicht ist das Kontrollzentrum für fertige Pläne, bevor Änderungen in den Hauptzweig Ihres Repositories einfließen.

## Funktionen

- **Git-Diff-Inspektion**: Zeigt Dateidiffs mit Syntaxhervorhebung für jeden beteiligten Worktree an.
- **Verifikationsergebnisse**: Überprüfen Sie Testprotokolle, Linter-Ergebnisse und Compiler-Warnungen vor der Freigabe.
- **Inline-Änderungsanfragen**: Fügen Sie Kommentare direkt im Plan hinzu und lassen Sie Tendril den Plan automatisch nachbessern.
- **Ein-Klick-PR-Erstellung**: Wandelt den genehmigten Plan über die GitHub CLI (`gh`) in einen Pull Request um.
