# Empfehlungen

Tendril analysiert Ihre Projekte kontinuierlich und generiert proaktive Empfehlungen für Refactorings, fehlende Tests und architektonische Verbesserungen.

## Vorschläge annehmen

- Überprüfen Sie die vorgeschlagene Änderung und Begründung.
- Wandeln Sie die Empfehlung mit einem Klick in einen ausführbaren Plan um.
- Alternativ können Sie direkt ein GitHub-Issue erstellen.
