# Copilot

Tendril integriert die GitHub Copilot CLI als autonomen Agenten.

## Voraussetzungen

- Ein aktives GitHub Copilot-Abonnement.
- Installierte GitHub CLI (`gh`) mit authentifizierter Copilot-Erweiterung:
  ```bash
  gh auth status
  ```
- Setzen Sie `codingAgent: copilot` in Ihrer `config.yaml`.
