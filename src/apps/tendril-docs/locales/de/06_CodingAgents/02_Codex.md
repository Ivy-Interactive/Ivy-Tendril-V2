# Codex

OpenAI-Modelle können als Coding-Agent in Tendril genutzt werden.

## Einrichtung

Stellen Sie sicher, dass Ihr OpenAI-API-Schlüssel in der Umgebung oder im Tendril Vault hinterlegt ist:

```yaml
codingAgent: codex
```

Unterstützt werden gängige Modelle wie `gpt-4o`, `o1` und `o3-mini`.
