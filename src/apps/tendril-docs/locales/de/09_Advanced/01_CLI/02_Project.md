# project Befehle

Verwalten Sie Projektkonfigurationen direkt über die Befehlszeile:

- `tendril project list`: Zeigt alle registrierten Projekte an.
- `tendril project add <PFAD>`: Registriert ein neues Git-Repository als Tendril-Projekt.
- `tendril project remove <NAME>`: Entfernt ein Projekt aus der Konfiguration.
