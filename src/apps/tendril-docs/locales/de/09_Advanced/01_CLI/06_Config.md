# config Befehle

Verwalten Sie Konfigurationseinstellungen:

- `tendril config get <SCHLÜSSEL>`: Liest einen Wert aus `config.yaml`.
- `tendril config set <SCHLÜSSEL> <WERT>`: Schreibt einen Wert in `config.yaml`.
