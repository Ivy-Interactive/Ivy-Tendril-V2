# verification Befehle

Verwalten Sie automatisierte Qualitätsprüfungen für Ihre Projekte:

- `tendril verification list`: Listet alle globalen und projektspezifischen Verifikationen auf.
- `tendril verification test <NAME>`: Führt eine Verifikationsprüfung testweise aus.
