# OpenClaw

OpenClaw ermöglicht die dateibasierte Übergabe von Aufgaben und Plänen an Tendril über einen Drop-Ordner im Dateisystem.

## Verwendung

Legen Sie Markdown-Dateien oder JSON-Spezifikationen in `$TENDRIL_HOME/Inbox/` ab. Tendril erkennt neue Dateien automatisch und reiht sie zur Bearbeitung ein.
