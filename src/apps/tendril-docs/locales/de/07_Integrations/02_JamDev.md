# Jam.dev

Mit Jam.dev können Tester und Benutzer visuelle Fehlerberichte erfassen, die Tendril direkt in ausführbare Pläne umwandelt.

## Funktionsweise

- Eingehende Jam-Webhooks landen im Tendril-Posteingang.
- Tendril analysiert Bildschirmaufnahmen, Fehler-Stacks und Netzwerk-Traces.
- `CreatePlan` generiert automatisch eine präzise Reproduktionsanleitung und einen Lösungsplan.
