# GitHub

Tendril lässt sich nahtlos in GitHub integrieren, um Issues in Pläne zu überführen und verifizierte Änderungen als Pull Requests einzureichen.

## Funktionen

- **Issue-Import**: Übertragen Sie GitHub-Issues direkt in neue Tendril-Pläne.
- **Automatische PR-Erstellung**: Nach erfolgreicher Verifikation erstellt Tendril den Pull Request über die GitHub CLI (`gh`).
- **Status-Synchronisation**: Verfolgen Sie CI-Status, Reviews und Merge-Ereignisse direkt in Tendril.
