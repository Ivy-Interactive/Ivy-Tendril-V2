# पुल रिक्वेस्ट्स (Pull Requests)

पुल रिक्वेस्ट्स (Pull Requests) ऐप स्वीकृत Tendril प्लांस से बनाए गए सभी [GitHub](https://github.com) पुल रिक्वेस्ट्स के लिए क्रॉस-प्रोजेक्ट ट्रैकिंग प्रदान करता है। यह प्रत्येक डिलीवरी से जुड़े टोकन खर्च और लागत के साथ-साथ यह निगरानी करने के लिए एक एकल डैशबोर्ड प्रदान करता है कि कौन से PRs खुले (open), मर्ज किए गए (merged), या बंद (closed) हैं।

## PR जीवनचक्र और वर्कफ़्लो (Lifecycle & Workflow)

1. **स्वीकृति (Approval)** — एक बार जब कोई प्लान निष्पादन समाप्त कर लेता है और [Review](02_Review.md) में स्वीकृत हो जाता है, तो **Create Pull Request** पर क्लिक करने से `CreatePr` प्रॉम्प्टवेयर लॉन्च होता है (देखें [प्रॉम्प्टवेयर्स (Promptwares)](../02_Concepts/02_Promptwares.md))।
2. **सृजन (Creation)** — Tendril आइसोलेटेड [Git](https://git-scm.com) वर्कस्ट्री ब्रांच को पुश करने और AI-जनरेटेड सारांश के साथ [GitHub](https://github.com) पर एक पुल रिक्वेस्ट खोलने के लिए [GitHub CLI](https://cli.github.com) (`gh`) का उपयोग करता है (देखें [GitHub एकीकरण (GitHub Integration)](../07_Integrations/01_Github.md))।
3. **ट्रैकिंग (Tracking)** — पुल रिक्वेस्ट को प्लान से लिंक किया जाता है और मर्ज या बंद होने तक इस दृश्य में ट्रैक किया जाता है।

## पुल रिक्वेस्ट्स तालिका (The Pull Requests Table)

यह तालिका आपके प्रोजेक्ट्स में रिकॉर्ड किए गए प्रत्येक पुल रिक्वेस्ट को सूचीबद्ध करती है:

| कॉलम           | विवरण                                                  | इंटरैक्शन                                                                                         |
| -------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| **Plan**       | प्लान `#ID` और शीर्षक।                                 | संपूर्ण प्लान विनिर्देश प्रदर्शित करने वाली स्लाइड-ओवर पूर्वावलोकन शीट खोलने के लिए क्लिक करें।   |
| **Project**    | प्रोजेक्ट बैज।                                         | [Project Setup](../03_Configuration/02_Projects.md) में परिभाषित प्रोजेक्ट रंग प्रदर्शित करता है। |
| **Status**     | स्थिति बैज (`Open`, `Merged`, `Closed`, या `Unknown`)। | होवर टूलटिप अंतिम GitHub जांच का टाइमस्टैम्प प्रदर्शित करता है।                                   |
| **PR**         | GitHub पुल रिक्वेस्ट संख्या (जैसे `#84`)।              | अपने डिफ़ॉल्ट ब्राउज़र में [GitHub](https://github.com) पर पुल रिक्वेस्ट खोलने के लिए क्लिक करें। |
| **Tokens**     | प्लान द्वारा उपभोग किए गए संचयी टोकन।                  | संक्षिप्त टोकन गणना (जैसे `450K`, `1.2M`)।                                                        |
| **Cost**       | इस प्लान के सभी जॉब्स के लिए कुल USD लागत।             | स्वरूपित मुद्रा व्यय।                                                                             |
| **Repository** | GitHub रिपॉजिटरी लक्ष्य (`owner/repo`)।                | पूर्ण लक्ष्य रिपॉजिटरी पथ।                                                                        |
| **Branch**     | Git ब्रांच का नाम।                                     | रिपॉजिटरी में स्रोत ब्रांच।                                                                       |

## फ़िल्टरिंग और सिंक्रोनाइज़ेशन (Filtering & Synchronization)

- **स्थिति फ़िल्टर (Status Filters)** — `Open`, `Merged`, `Closed`, या `Unknown` द्वारा फ़िल्टर करने के लिए तालिका के ऊपर स्थिति बैज चयनकर्ता का उपयोग करें।
- **खोज (Search)** — प्लान ID, शीर्षक, प्रोजेक्ट का नाम, रिपॉजिटरी, या ब्रांच के नाम के आधार पर पंक्तियों को रीयल-टाइम में फ़िल्टर करें।
- **GitHub के साथ पुनः सिंक करें (Resync with GitHub)** — कॉन्फ़िगर की गई रिपॉजिटरी में सिंक्रोनाइज़ेशन पास (`gh pr list`) चलाने के लिए **Resync** बटन पर क्लिक करें। Tendril किसी भी अगम्य, अप्रमाणित या दर-सीमित (rate-limited) रिपॉजिटरी की रिपोर्ट करता है।

> [!NOTE]
> मर्ज किए गए पुल रिक्वेस्ट टर्मिनल होते हैं और आवधिक सिंक पास के दौरान उनकी दोबारा जांच नहीं की जाती है।

## पंक्ति क्रियाएं (Row Actions)

प्रत्येक पुल रिक्वेस्ट पंक्ति चार त्वरित क्रियाएं प्रदान करती है:

- **View Plan** — [Plans](03_Plans.md) ऐप में प्लान के विवरण वर्कस्पेस पर ले जाता है।
- **Follow Up** — रिपॉजिटरी, प्रोजेक्ट और ब्रांच संदर्भ के साथ पहले से भरा हुआ नया प्लान संवाद खोलता है ताकि आप [Plans](03_Plans.md) में फॉलो-अप कार्यों, बग फिक्स या सुधारों को आसानी से तैयार कर सकें।
- **Open PR** — आपके वेब ब्राउज़र में [GitHub](https://github.com) पर पुल रिक्वेस्ट खोलता है।
- **Resync** — उस विशिष्ट रिपॉजिटरी के लिए GitHub से स्थिति को रीफ़्रेश करता है।
