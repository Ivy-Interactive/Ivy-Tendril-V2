# MCP सर्वर

Tendril में एक Model Context Protocol (MCP) सर्वर शामिल है जो Claude Code जैसे AI कोडिंग एजेंटों के लिए प्लान प्रबंधन, जॉब ऑर्केस्ट्रेशन और प्रोजेक्ट डिस्कवरी टूल्स उपलब्ध कराता है।

## MCP सर्वर शुरू करना

```bash
tendril mcp
```

यह stdio ट्रांसपोर्ट के माध्यम से MCP सर्वर लॉन्च करता है, जो Claude Code के MCP कॉन्फ़िगरेशन में उपयोग के लिए उपयुक्त है। मानक इनपुट और आउटपुट (Standard input and output) विशेष रूप से JSON-RPC संदेशों के लिए आरक्षित हैं; नैदानिक लॉग (diagnostic logs) stderr पर निर्देशित किए जाते हैं।

## प्रमाणीकरण

MCP सत्रों के लिए टोकन प्रमाणीकरण की आवश्यकता हेतु `TENDRIL_MCP_TOKEN` पर्यावरण चर (environment variable) सेट करें:

- **पर्यावरण चर**: stdio पर कनेक्ट होने वाले क्लाइंट `TENDRIL_MCP_CLIENT_TOKEN` (या `TENDRIL_MCP_TOKEN`) के माध्यम से मिलान टोकन प्रदान कर सकते हैं।
- **अनुरोध मेटाडेटा**: क्लाइंट `_meta["io.tendril/token"]` के अंतर्गत `initialize` पैरामीटर में प्रति-अनुरोध टोकन भी पास कर सकते हैं।

जब `TENDRIL_MCP_TOKEN` अनसेट या रिक्त होता है, तो प्रमाणीकरण अक्षम हो जाता है और स्थानीय अनुरोधों की अनुमति होती है।

## उपलब्ध टूल्स

सभी टूल्स `tendril_` से उपसर्गित हैं और सीधे डेमॉन या स्थानीय Tendril स्टोरेज पर काम करते हैं।

### प्लान निरीक्षण और क्वेरी

| टूल                              | पैरामीटर्स                                                           | विवरण                                                                                                                                                                                                                              |
| -------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tendril_get_plan`               | `plan_id` (आवश्यक), `field` (वैकल्पिक)                               | किसी प्लान का मेटाडेटा और नवीनतम संशोधन प्राप्त करें। जब `field` निर्दिष्ट होता है, तो केवल वही फ़ील्ड लौटाता है (उदा. `title`, `state`, `project`, `level`, `repos`, `commits`, `prs`, `verifications`, `dependsOn`, `revision`)। |
| `tendril_list_plans`             | `state` (वैकल्पिक), `project` (वैकल्पिक), `search`, `since`, `limit` | फ़िल्टर से मेल खाने वाले प्लान सूचीबद्ध करें। `since` RFC 3339 टाइमस्टैम्प स्वीकार करता है; `search` शीर्षक या ID द्वारा फ़िल्टर करता है।                                                                                          |
| `tendril_get_revision`           | `plan_id` (आवश्यक), `number` (वैकल्पिक)                              | किसी प्लान संशोधन का मार्कडाउन टेक्स्ट प्राप्त करें (डिफ़ॉल्ट रूप से नवीनतम, या एक विशिष्ट संशोधन संख्या)।                                                                                                                         |
| `tendril_plan_validate`          | `plan_id` (आवश्यक)                                                   | प्लान की स्थिति जांचें और किसी भी संरचनात्मक या स्कीमा समस्याओं की रिपोर्ट करें।                                                                                                                                                   |
| `tendril_plan_verification_list` | `plan_id` (आवश्यक)                                                   | किसी प्लान के लिए सभी सत्यापन और उनकी वर्तमान स्थितियां (`Pending`, `Pass`, `Fail`, `Skipped`) सूचीबद्ध करें।                                                                                                                      |
| `tendril_plan_rec_list`          | `plan_id` (आवश्यक), `state` (वैकल्पिक)                               | किसी प्लान के लिए सिफारिशें सूचीबद्ध करें। फ़िल्टर स्थितियां: `Pending`, `Accepted`, `AcceptedWithNotes`, `Declined`।                                                                                                              |

> [!NOTE]
> कॉन्फ़िगरेशन MCP पर केवल-पढ़ने योग्य (read-only) है: मशीन-व्यापी सेटिंग्स जैसे `planFolder` या `codingAgent` को संशोधित करने के लिए CLI (`tendril config set`) या Tendril UI का उपयोग करने की आवश्यकता होती है।

## Claude Code कॉन्फ़िगरेशन

अपनी Claude Code सेटिंग्स (`~/.claude/settings.json` या प्रोजेक्ट-स्तरीय `.claude/settings.json`) में Tendril का MCP सर्वर जोड़ें:

```json
{
  "mcpServers": {
    "tendril": {
      "command": "tendril",
      "args": ["mcp"]
    }
  }
}
```

टोकन प्रमाणीकरण सक्षम होने पर:

```json
{
  "mcpServers": {
    "tendril": {
      "command": "tendril",
      "args": ["mcp"],
      "env": {
        "TENDRIL_MCP_CLIENT_TOKEN": "your-secret-token"
      }
    }
  }
}
```
