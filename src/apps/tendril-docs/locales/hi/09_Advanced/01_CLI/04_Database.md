# डेटाबेस

स्थानीय [SQLite](https://www.sqlite.org) डेटाबेस (`<TendrilHome>/tendril.db`) को प्रबंधित करें जो [योजना सिंक डेटा](../../02_Concepts/01_Plans.md), [जॉब इतिहास](../../04_Apps/04_Jobs.md), सिफ़ारिशें और लागत ट्रैकिंग संग्रहीत करता है। Tendril v2 में, सभी डेटाबेस प्रबंधन को `tendril db` उप-कमांड ट्री के माध्यम से एक्सेस किया जाता है।

## कमांड

#### db version

```terminal
>tendril db version
```

माइग्रेशन लागू किए बिना डेटाबेस स्कीमा का निरीक्षण करता है। वर्तमान डेटाबेस संस्करण, इंस्टॉल किए गए बाइनरी द्वारा अपेक्षित नवीनतम संस्करण और माइग्रेशन स्थिति (`Up to date`, `Needs migration`, या `Newer than application`) प्रिंट करता है।

```terminal
Database version: 12
Latest version:   12
Status:           Up to date
```

#### db migrate

```terminal
>tendril db migrate
```

डेटाबेस स्कीमा को अद्यतित करने के लिए सभी लंबित माइग्रेशन लागू करता है। बार-बार चलाना सुरक्षित है — पहले से लागू किए गए माइग्रेशन को निष्क्रिय रूप से छोड़ दिया जाता है।

> [!NOTE]
> `tendril run` डेमॉन सर्वर शुरू करने से पहले स्वचालित रूप से लंबित माइग्रेशन लागू करता है, इसलिए मैन्युअल माइग्रेशन की शायद ही कभी आवश्यकता होती है।

#### db reset

```terminal
>tendril db reset
>tendril db reset --force
```

`tendril.db` में प्रत्येक तालिका को हटाता है (ड्रॉप करता है) और शुरुआत से स्कीमा को फिर से बनाता है। जब तक `--force` प्रदान नहीं किया जाता है, तब तक पुष्टि के लिए संकेत देता है। यदि डेमॉन वर्तमान में सक्रिय है, तो चलने से मना कर देता है जब तक कि `--force` नहीं दिया जाता है।

> [!WARNING]
> रीसेट करने से सभी डेटाबेस रिकॉर्ड (कैश किया गया जॉब इतिहास, टेलीमेट्री, सिफ़ारिशें) हट जाते हैं। डिस्क पर आपकी लिखित [योजना YAML फ़ाइलें](01_Plan.md) और संशोधन मार्कडाउन फ़ाइलें पूरी तरह से अप्रभावित रहती हैं।

#### db integrity

```terminal
>tendril db integrity
```

सभी तालिकाओं, अनुक्रमणिकाओं (indices) और पृष्ठों पर SQLite [PRAGMA integrity_check](https://www.sqlite.org/pragma.html#pragma_integrity_check) चलाता है। प्रत्येक सत्यापन परिणाम प्रिंट करता है और यदि कोई खराबी या संरचनात्मक विसंगति पाई जाती है तो कोड 1 के साथ बाहर निकल जाता है।

#### db vacuum

```terminal
>tendril db vacuum
>tendril db vacuum --force
```

डेटाबेस को डीफ़्रैग्मेंट करने, अनुक्रमणिकाओं (indices) को फिर से बनाने और अप्रयुक्त डिस्क स्थान को पुनः प्राप्त करने के लिए SQLite [VACUUM](https://www.sqlite.org/lang_vacuum.html) निष्पादित करता है। निष्पादन से पहले और बाद में डेटाबेस आकार के साथ-साथ पुनः प्राप्त कुल बाइट्स की रिपोर्ट करता है।
