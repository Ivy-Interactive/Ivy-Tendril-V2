# सीएलआई (CLI)

Tendril कमांड लाइन इंटरफ़ेस सीधे आपके टर्मिनल से प्लान्स, प्रोजेक्ट्स, डेटाबेस और डेमॉन प्रक्रियाओं को प्रबंधित करने के लिए कमांड प्रदान करता है।

- [सीएलआई अवलोकन](00_Overview.md) — ग्लोबल विकल्प, पर्यावरण चर (environment variables), और आवश्यक समस्या निवारण (troubleshooting) कमांड।
- [plan](01_Plan.md) — प्लान्स, वर्क-ट्रीज़ (worktrees), रिवीज़न और वेरिफ़िकेशन बनाएं, सूचीबद्ध करें, अपडेट करें और मान्य (validate) करें।
- [project](02_Project.md) — प्रोजेक्ट्स, रिपॉजिटरीज़, बिल्ड निर्भरताएं (dependencies), समीक्षा क्रियाएं (review actions), MCP सर्वर्स, और स्किल्स को कॉन्फ़िगर करें।
- [verification](03_Verification.md) — पुन: प्रयोज्य (reusable) ग्लोबल वेरिफ़िकेशन जांचों को परिभाषित और प्रबंधित करें।
- [डेटाबेस](04_Database.md) — स्कीमा संस्करण, माइग्रेशन, डेटाबेस रीसेट, अखंडता जांच (integrity checks), और वैक्यूम (vacuum)।
- [अन्य कमांड्स](05_Other.md) — प्रॉम्प्टवेयर निष्पादन (promptware execution), जॉब ट्रैकिंग, चैट सेशन्स, सेवा पंजीकरण (service registration), और उपयोगिताएँ (utilities)।
- [config](06_Config.md) — `config.yaml` में संग्रहीत शीर्ष-स्तरीय सेटिंग्स पढ़ें और अपडेट करें।
- [vault](07_Vault.md) — टीम वॉल्ट्स कनेक्ट करें, साझा रिपॉजिटरीज़ खोजें, और प्रोजेक्ट्स आयात (import) या प्रकाशित (publish) करें।
