# उन्नत

Ivy Tendril के लिए उन्नत कॉन्फ़िगरेशन, डीमन ऑटोमेशन और CLI टूल्स को एक्सप्लोर करें।

यह अनुभाग कमांड लाइन इंटरफ़ेस, प्रोग्रामेटिक प्लान और जॉब निष्पादन के लिए REST डीमन एंडपॉइंट्स, और कोडिंग एजेंट्स के लिए उपलब्ध Model Context Protocol (MCP) सर्वर्स को कवर करता है।

- [CLI संदर्भ](01_CLI/_Index.md) — `tendril` कमांड लाइन इंटरफ़ेस, सब-कमांड्स और फ़्लैग्स के लिए पूर्ण संदर्भ।
- [REST API](02_REST.md) — प्रोग्रामेटिक प्लान निष्पादन, जॉब प्रबंधन, इनबॉक्स सबमिशन और हेल्थ चेक के लिए डीमन एंडपॉइंट्स।
- [MCP सर्वर](03_MCP.md) — Claude Code जैसे AI कोडिंग एजेंट्स के लिए उपलब्ध टूल्स और संसाधन।
