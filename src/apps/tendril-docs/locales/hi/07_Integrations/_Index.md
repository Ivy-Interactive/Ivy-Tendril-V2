# एकीकरण (Integrations)

अपने विकास कार्यप्रवाह को सुव्यवस्थित करने और [योजना निष्पादन (plan execution)](../02_Concepts/01_Plans.md) को स्वचालित करने के लिए Tendril को बाहरी टूल्स और सेवाओं के साथ कनेक्ट करें।

- [GitHub](01_Github.md) — [GitHub](https://github.com) के साथ समस्या (issue) आयात करना, स्वचालित पुल अनुरोध (pull request) निर्माण, और PR स्थिति तुल्यकालन (synchronization)।
- [Jam.dev](02_JamDev.md) — [Jam.dev](https://jam.dev) इनबॉक्स API वेबहुक के माध्यम से बग रिपोर्ट से स्वचालित योजना निर्माण।
- [OpenClaw](03_OpenClaw.md) — Tendril इनबॉक्स ड्रॉप फ़ोल्डर के माध्यम से OpenClaw जैसे बाहरी टूल्स से फ़ाइल-आधारित योजना अंतर्ग्रहण (ingestion)।
