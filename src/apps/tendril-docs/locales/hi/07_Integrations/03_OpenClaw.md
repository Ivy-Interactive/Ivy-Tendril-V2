# OpenClaw

## सिंहावलोकन

Tendril नई markdown फ़ाइलों के लिए एक **Inbox फ़ोल्डर** पर नज़र रखता है और उन्हें स्वचालित रूप से [plans](../02_Concepts/01_Plans.md) में परिवर्तित करता है। यह OpenClaw जैसे बाहरी टूल्स या डिस्क पर फ़ाइलें लिखने वाले कस्टम स्क्रिप्ट्स के लिए एक सरल, फ़ाइल-आधारित एकीकरण बिंदु प्रदान करता है।

## Inbox फ़ोल्डर का स्थान

```
$TENDRIL_HOME/Inbox/
```

Tendril होम डायरेक्टरी और कॉन्फ़िगरेशन के विवरण के लिए, [Setup & Settings](../03_Configuration/01_Setup.md) देखें। Tendril का फ़ाइलसिस्टम वॉचर नई `.md` फ़ाइलों के लिए इस डायरेक्टरी की निगरानी करता है।

## फ़ाइल प्रारूप

वैकल्पिक YAML frontmatter के साथ एक markdown फ़ाइल (`.md`) डालें:

```markdown
---
project: ProjectName
sourcePath: optional/path/to/code
---

Describe the plan here. This text becomes the plan description
and is passed to the [CreatePlan promptware](../02_Concepts/02_Promptwares.md).
```

| फ़ील्ड       | आवश्यक | विवरण                                            |
| ------------ | ------ | ------------------------------------------------ |
| `project`    | नहीं   | लक्षित प्रोजेक्ट का नाम (डिफ़ॉल्ट रूप से `Auto`) |
| `sourcePath` | नहीं   | संबंधित सोर्स कोड के लिए पाथ संकेत               |

Frontmatter के बाद की सामग्री योजना का विवरण बन जाती है।

> [!NOTE]
> यदि आप frontmatter को पूरी तरह से छोड़ देते हैं, तो डिफ़ॉल्ट सेटिंग्स के साथ पूरी फ़ाइल सामग्री का उपयोग योजना विवरण के रूप में किया जाता है।

## फ़ाइल का जीवनचक्र

1. Inbox फ़ोल्डर में एक `.md` फ़ाइल **डालें (Drop)**
2. **प्रसंस्करण (Processing)** — संभाले जाने के दौरान फ़ाइल का नाम बदलकर `.md.processing` कर दिया जाता है
3. **पूर्णता (Completion)** — योजना सफलतापूर्वक बनने के बाद फ़ाइल हटा दी जाती है

## पुनर्प्राप्ति (Recovery)

यदि प्रसंस्करण के दौरान Tendril पुनरारंभ (restart) होता है, तो कोई भी `.md.processing` फ़ाइलें स्वचालित रूप से वापस `.md` में पुनर्प्राप्त हो जाती हैं और स्टार्टअप पर पुन: संसाधित की जाती हैं।

## OpenClaw के साथ सेटअप करना

अपने आउटपुट को Tendril Inbox फ़ोल्डर में markdown फ़ाइलों के रूप में लिखने के लिए OpenClaw को कॉन्फ़िगर करें। प्रत्येक फ़ाइल एक अलग योजना बन जाती है:

1. आउटपुट डायरेक्टरी को `$TENDRIL_HOME/Inbox/` पर सेट करें
2. प्रोजेक्ट लक्ष्यीकरण के लिए YAML frontmatter के साथ markdown प्रारूप का उपयोग करें
3. Tendril स्वचालित रूप से नई फ़ाइलों को उठा लेता है — किसी पोलिंग या API कॉल की आवश्यकता नहीं है
