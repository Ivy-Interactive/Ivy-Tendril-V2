# शुरुआत करना

पढ़ने के क्रम में छह पृष्ठ। पहले दो Tendril को चालू करते हैं; अगले दो इसे आपकी अपनी रिपॉजिटरी पर _स्वायत्त (unattended)_ रूप से चलाते हैं, जो कि इसका मुख्य लाभ है।

- [परिचय](01_Introduction.md) — Tendril क्या है, इसे कैसे बनाया गया है, और यह इस तरह से क्यों काम करता है।
- [इंस्टॉलेशन](02_Installation.md) — पूर्वापेक्षाएँ (prerequisites), सोर्स से बिल्ड करना, और कॉन्फ़िगरेशन कहाँ रहता है।
- [कोडबेस को ऑनबोर्ड करना](03_Onboarding.md) — अपनी पहली वास्तविक योजना से पहले पूरी करने योग्य मशीन और रिपॉजिटरी चेकलिस्ट।
- [ट्यूटोरियल](04_Tutorial.md) — एक पूर्ण लूप: एक प्रोजेक्ट रजिस्टर करें, एक योजना बनाएं, इसे निष्पादित करें, diff की समीक्षा करें, एक pull request खोलें।
- [मदद प्राप्त करना](05_GettingHelp.md) — Discord, GitHub issues, और बग रिपोर्ट के साथ क्या संलग्न करना है।
- [समस्या निवारण](06_Troubleshooting.md) — क्षेत्र के अनुसार लक्षण और समाधान।

जब आप इन्हें पूरा कर लें, तो [अवधारणाएं](../02_Concepts/_Index.md) इसके अंतर्निहित मॉडल की व्याख्या करता है:
[योजनाएं (plans)](../02_Concepts/01_Plans.md), [प्रॉम्प्टवेयर्स (promptwares)](../02_Concepts/02_Promptwares.md), और
[जॉब का जीवनचक्र (job lifecycle)](../02_Concepts/03_Lifecycle.md)।
