# सहायता प्राप्त करना

यदि आपको समस्याओं का सामना करना पड़ता है या Tendril को कॉन्फ़िगर करने के बारे में कोई प्रश्न हैं, तो कई सहायता संसाधन और डायग्नोस्टिक उपकरण उपलब्ध हैं।

## पहले डायग्नोस्टिक्स चलाएँ

कोई समस्या सबमिट करने या सहायता मांगने से पहले, Tendril का इन-बिल्ट एनवायरनमेंट डॉक्टर चलाएँ:

```bash
tendril doctor
```

`tendril doctor` आपके `$TENDRIL_HOME` डायरेक्टरी, `config.yaml` सिंटैक्स, [SQLite](https://www.sqlite.org) डेटाबेस एक्सेसिबिलिटी, [plans](../02_Concepts/01_Plans.md) डायरेक्टरी, [Git](https://git-scm.com/), और [GitHub CLI](https://cli.github.com/) ऑथेंटिकेशन की पुष्टि करता है।

यदि कोई विशिष्ट योजना (plan) या कार्य (job) विफल हो जाता है, तो आप `tendril report-bug` का उपयोग करके पूर्ण डायग्नोस्टिक्स को बंडल कर सकते हैं:

```bash
# Package plan state, verification reports, and job logs into a zip
tendril report-bug <plan-id>
```

यह एक डायग्नोस्टिक आर्काइव बनाता है जो संवेदनशील क्रेडेंशियल्स को उजागर किए बिना plan YAML, रिवीजन हिस्ट्री, वेरिफिकेशन आउटपुट, और रॉ एजेंट ट्रांसक्रिप्ट्स को पैकेज करता है।

## समस्या निवारण (Troubleshooting)

सामान्य त्रुटि संदेशों, डेटाबेस माइग्रेशन और वर्कस्ट्री रिकवरी चरणों के लिए, [समस्या निवारण](06_Troubleshooting.md) देखें।

## Discord समुदाय

डेवलपमेंट टीम और अन्य बिल्डर्स तक पहुँचने का सबसे तेज़ तरीका हमारा [Discord सर्वर](https://discord.gg/FHgxkDga3y) है। प्रश्न पूछने, फ़ीडबैक साझा करने, और कस्टम प्रॉम्प्टवेयर वर्कफ़्लो पर चर्चा करने के लिए जुड़ें।

## GitHub issues

कोई बग मिला या किसी नए फ़ीचर का अनुरोध करना चाहते हैं? हमारे [GitHub रिपॉजिटरी](https://github.com/Ivy-Interactive/Ivy-Tendril-V2/issues) पर एक समस्या (issue) दर्ज करें।

> [!TIP]
> अपने issue विवरण में हमेशा `tendril doctor` और `tendril version` का आउटपुट शामिल करें। यदि किसी विफल plan निष्पादन की रिपोर्ट कर रहे हैं, तो `tendril report-bug <plan-id>` द्वारा जनरेट की गई डायग्नोस्टिक zip या `$TENDRIL_HOME/Jobs/` से जॉब लॉग संलग्न करें।
