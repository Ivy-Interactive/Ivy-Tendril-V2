# Avançado

Explore a configuração avançada, a automação do daemon e as ferramentas de CLI para o Ivy Tendril.

Esta seção aborda a interface de linha de comando, os endpoints REST do daemon para execução programática de planos e jobs, e os servidores do Model Context Protocol (MCP) expostos a agentes de programação.

- [Referência da CLI](01_CLI/_Index.md) — referência completa da interface de linha de comando do `tendril`, subcomandos e flags.
- [API REST](02_REST.md) — endpoints do daemon para execução programática de planos, gerenciamento de jobs, envios para a caixa de entrada e verificações de integridade.
- [Servidor MCP](03_MCP.md) — ferramentas e recursos expostos a agentes de programação com IA como o Claude Code.
