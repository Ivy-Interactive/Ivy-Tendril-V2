# Integrações

Conecte o Tendril com ferramentas e serviços externos para simplificar o seu fluxo de desenvolvimento e automatizar a [execução de planos](../02_Concepts/01_Plans.md).

- [GitHub](01_Github.md) — importação de issues, criação automática de pull requests e sincronização de status de PR com o [GitHub](https://github.com).
- [Jam.dev](02_JamDev.md) — criação automatizada de planos a partir de relatórios de bugs via webhook da API de inbox do [Jam.dev](https://jam.dev).
- [OpenClaw](03_OpenClaw.md) — ingestão de planos baseada em arquivos a partir de ferramentas externas como o OpenClaw através da pasta drop do Tendril Inbox.
