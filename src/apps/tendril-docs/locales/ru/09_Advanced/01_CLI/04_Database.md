# База данных

Управление локальной базой данных [SQLite](https://www.sqlite.org) (`<TendrilHome>/tendril.db`), в которой хранятся [данные синхронизации планов](../../02_Concepts/01_Plans.md), [история задач](../../04_Apps/04_Jobs.md), рекомендации и учет затрат. В Tendril v2 все операции по управлению базой данных осуществляются через дерево подкоманд `tendril db`.

## Команды

#### db version

```terminal
>tendril db version
```

Проверяет схему базы данных без применения миграций. Выводит текущую версию базы данных, последнюю версию, ожидаемую установленным бинарным файлом, и статус миграции (`Up to date`, `Needs migration` или `Newer than application`).

```terminal
Database version: 12
Latest version:   12
Status:           Up to date
```

#### db migrate

```terminal
>tendril db migrate
```

Применяет все ожидающие миграции, чтобы обновить схему базы данных до актуального состояния. Безопасно для повторного запуска — уже примененные миграции идемпотентно пропускаются.

> [!NOTE]
> Команда `tendril run` автоматически применяет ожидающие миграции перед запуском сервера демона, поэтому ручная миграция требуется редко.

#### db reset

```terminal
>tendril db reset
>tendril db reset --force
```

Удаляет все таблицы в `tendril.db` и воссоздает схему с нуля. Запрашивает подтверждение, если не указан флаг `--force`. Отказывается выполнять операцию при активном демоне, если не указан флаг `--force`.

> [!WARNING]
> Сброс удаляет все записи в базе данных (кэшированную историю задач, телеметрию, рекомендации). Созданные вами [файлы планов YAML](01_Plan.md) и markdown-файлы ревизий на диске остаются полностью нетронутыми.

#### db integrity

```terminal
>tendril db integrity
```

Выполняет команду SQLite [PRAGMA integrity_check](https://www.sqlite.org/pragma.html#pragma_integrity_check) для всех таблиц, индексов и страниц. Выводит результат каждой проверки и завершает работу с кодом 1 при обнаружении повреждений или структурных аномалий.

#### db vacuum

```terminal
>tendril db vacuum
>tendril db vacuum --force
```

Выполняет команду SQLite [VACUUM](https://www.sqlite.org/lang_vacuum.html) для дефрагментации базы данных, перестроения индексов и освобождения неиспользуемого дискового пространства. Сообщает размер базы данных до и после выполнения, а также общий объем освобожденных байтов.
