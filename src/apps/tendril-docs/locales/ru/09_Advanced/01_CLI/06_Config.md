# Конфигурация

Получайте и задавайте параметры конфигурации верхнего уровня Tendril, хранящиеся в формате [YAML](https://yaml.org) внутри `config.yaml` — те же глобальные значения, которыми можно управлять в разделе «Настройки» в десктопном и веб-интерфейсах. Дополнительные сведения об окружении и структуре каталогов см. в [Руководстве по установке](../../03_Configuration/01_Setup.md).

## Команды

```terminal
>tendril config get <key>
>tendril config set <key> <value>
```

- **`get`** — Выводит необработанное значение в стандартный вывод без декоративного форматирования, что делает его идеальным для скриптов командной строки и передачи через конвейер напрямую в файлы или другие инструменты.
- **`set`** — Проверяет и обновляет значение в `config.yaml`. Ключи нечувствительны к регистру.

## Простые ключи

Tendril моделирует несколько простых ключей конфигурации с типизированной валидацией:

| Ключ                           | Тип                                 | По умолчанию       | Описание                                                                                                                                                  |
| ------------------------------ | ----------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `codingAgent`                  | string                              | `claude`           | Исполняемый файл или псевдоним агента кодирования по умолчанию (например, `claude`, `aider`, `codestory`).                                                |
| `jobTimeout`                   | integer (минуты)                    | `120`              | Максимальный таймаут выполнения для запущенной задачи плана.                                                                                              |
| `staleOutputTimeout`           | integer (минуты)                    | `10`               | Длительность бездействия до того, как задача без вывода будет помечена как зависшая.                                                                      |
| `gitTimeout`                   | integer (минуты)                    | `5`                | Таймаут команд для операций [Git](https://git-scm.com).                                                                                                   |
| `daemonRequestTimeout`         | integer (секунды)                   | `30`               | Таймаут в секундах для HTTP-запросов к локальному демону Tendril (`0` или отрицательное значение отключает).                                              |
| `maxConcurrentJobs`            | integer                             | `2`                | Максимально допустимое количество одновременно выполняемых задач.                                                                                         |
| `planTemplate`                 | string                              | `""`               | Шаблон [Markdown](https://daringfireball.net/projects/markdown/), добавляемый в начало при создании новых планов.                                         |
| `planFolder`                   | string (необязательно)              | `None`             | Пользовательский каталог файловой системы для хранения markdown-файлов планов. Передайте `""` для сброса.                                                 |
| `promptwareOverlay`            | string (необязательно)              | `None`             | Путь к каталогу наложения, содержащему пользовательские promptware. Передайте `""` для сброса.                                                            |
| `telemetry`                    | boolean (необязательно)             | `None`             | Переключатель добровольной анонимной телеметрии (`true` или `false`). Передайте `""` для очистки.                                                         |
| `beta`                         | boolean                             | `false`            | Включает экспериментальные предварительные функции (`true` или `false`).                                                                                  |
| `desktopNotifications`         | boolean                             | `true`             | Включает системные уведомления рабочего стола о статусе плана и завершении работы агента (`true` или `false`).                                            |
| `theme`                        | string                              | `default`          | Идентификатор цветовой схемы пользовательского интерфейса (например, `default`, `dracula`).                                                               |
| `worktreeReaperInterval`       | integer (минуты)                    | `60`               | Частота автоматических запусков очистки рабочих деревьев [Git](https://git-scm.com) (`0` или отрицательное значение отключает).                           |
| `worktreeReaperGrace`          | integer (минуты)                    | `1440`             | Льготный период бездействия в минутах до того, как неактивное рабочее дерево будет признано подлежащим очистке.                                           |
| `worktreeBranchDeleteMode`     | string                              | `PreserveUnpushed` | Режим безопасности при удалении веток во время очистки рабочего дерева (`PreserveUnpushed` или `Force`).                                                  |
| `coAuthor`                     | string (необязательно)              | `None`             | Идентификатор авторства в трейлере [Git](https://git-scm.com) в формате `Name <email>`, добавляемый к автоматическим коммитам. Передайте `""` для сброса. |
| `enrichModels`                 | boolean                             | `true`             | Включает автоматическое фоновое обнаружение и обогащение моделей (`true` или `false`).                                                                    |
| `modelEnrichmentIntervalHours` | integer (часы)                      | `24`               | Интервал фонового обновления метаданных моделей.                                                                                                          |
| `modelCacheWarnAgeDays`        | integer (дни)                       | `7`                | Мягкий порог давности, после которого устаревший кэш моделей вызывает предупреждения.                                                                     |
| `modelCacheMaxAgeDays`         | integer (дни)                       | `30`               | Жесткий порог давности, после которого срок действия кэшированных метаданных моделей истекает.                                                            |
| `llm`                          | объект [JSON](https://www.json.org) | `None`             | Эндпоинт, API-ключ и конфигурация модели для вспомогательного сервиса LLM. Объединяется с существующими полями.                                           |

> [!NOTE]
> Несмоделированные скалярные ключи также могут сохраняться и извлекаться; они хранятся в таблице дополнительных атрибутов в `config.yaml`.

## Структурированные ключи

Настройки Tendril также содержат структурированные списки и ассоциативные массивы (maps), которые нельзя задать или получить через `tendril config`:

- `projects` — Определения настроенных проектов (управляются с помощью [`tendril project`](02_Project.md)).
- `verifications` — Глобальные определения наборов проверок (управляются с помощью [`tendril verification`](03_Verification.md)).
- `levels` — Уровни сложности плана и привязки проверок.
- `onboarding` — Состояния завершения мастера первого запуска.
- `codingAgents` — Пути к бинарным файлам, аргументы, переменные окружения и профили для каждого агента.
- `promptwares` — Инструкции, профили и правила для инструментов для каждого promptware.
- `inbox` — Правила входящих уведомлений и интеграции доставки.

Попытка выполнить `tendril config get` или `tendril config set` для любого структурированного ключа выводит ошибку с указанием использовать специальную команду CLI или отредактировать `config.yaml` напрямую.

## Примеры

```terminal
># Чтение значения конфигурации
>tendril config get jobTimeout

># Обновление числового или текстового параметра
>tendril config set jobTimeout 60
>tendril config set codingAgent claude

># Переключение логических параметров
>tendril config set desktopNotifications false
>tendril config set beta true

># Объединение конфигурации вспомогательной LLM
>tendril config set llm '{"model":"gpt-4o"}'

># Очистка необязательного параметра путем передачи пустой строки
>tendril config set coAuthor ""
>tendril config set planFolder ""

># Установка многострочного шаблона плана с использованием подстановки команд оболочки
>tendril config set planTemplate "$(cat template.md)"

># Экспорт шаблона плана обратно в файл
>tendril config get planTemplate > template.md
```

> [!TIP]
> При назначении многострочного текста, такого как `planTemplate`, или объектов [JSON](https://www.json.org), таких как `llm`, используйте кавычки командной оболочки или подстановку команд (`"$(cat file.md)"`), чтобы значения передавались корректно в виде единого аргумента.
