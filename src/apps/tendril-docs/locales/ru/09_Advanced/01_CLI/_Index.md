# CLI

Интерфейс командной строки Tendril предоставляет команды для управления планами, проектами, базами данных и фоновыми процессами (демонами) прямо из вашего терминала.

- [Обзор CLI](00_Overview.md) — глобальные параметры, переменные окружения и основные команды для устранения неполадок.
- [plan](01_Plan.md) — создание, вывод списка, обновление и валидация планов, рабочих деревьев (worktrees), ревизий и проверок.
- [project](02_Project.md) — настройка проектов, репозиториев, зависимостей сборки, действий проверки (review actions), MCP-серверов и навыков.
- [verification](03_Verification.md) — определение и управление переиспользуемыми глобальными верификационными проверками.
- [База данных](04_Database.md) — версии схемы, миграции, сброс базы данных, проверки целостности и вакуумирование (vacuum).
- [Другие команды](05_Other.md) — выполнение promptware, отслеживание задач, сессии чата, регистрация сервисов и утилиты.
- [config](06_Config.md) — чтение и обновление параметров верхнего уровня, сохраненных в `config.yaml`.
- [vault](07_Vault.md) — подключение командных хранилищ (vaults), поиск общих репозиториев, а также импорт и публикация проектов.
