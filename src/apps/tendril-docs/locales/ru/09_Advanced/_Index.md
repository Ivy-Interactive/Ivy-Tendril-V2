# Продвинутый уровень

Изучите расширенную конфигурацию, автоматизацию демона и инструменты CLI для Ivy Tendril.

В этом разделе рассматриваются интерфейс командной строки, эндпоинты REST-демона для программного выполнения планов и задач, а также серверы Model Context Protocol (MCP), предоставляемые агентам написания кода.

- [Справочник по CLI](01_CLI/_Index.md) — полный справочник по интерфейсу командной строки `tendril`, подкомандам и флагам.
- [REST API](02_REST.md) — эндпоинты демона для программного выполнения планов, управления задачами, отправки во входящие и проверок работоспособности.
- [MCP-сервер](03_MCP.md) — инструменты и ресурсы, предоставляемые ИИ-агентам написания кода, таким как Claude Code.
