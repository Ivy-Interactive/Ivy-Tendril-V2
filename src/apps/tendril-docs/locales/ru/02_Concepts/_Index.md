# Концепции

Tendril обладает лаконичной концептуальной моделью, и любая функция в десктопном приложении и CLI сопоставляется с одним из
трёх базовых примитивов:

- [Планы](01_Plans.md) — фундаментальная единица работы. План представляет собой прозрачную папку на диске, конечный автомат
  состояний, неизменяемый набор ревизий, встроенные аннотации и автоматические верификации.
- [Промптвары](02_Promptwares.md) — узкоспециализированные агенты рабочих процессов, которые переводят план из одного состояния
  в другое, каждый со своим системным промптом, ограниченным набором инструментов и долговременной памятью.
- [Жизненный цикл и задания](03_Lifecycle.md) — один запуск одного промптвара для плана образует задание (job):
  статус, телеметрия, изолированные рабочие деревья git, отслеживание затрат и критерии качества, определяющие переход работы к ревью.

Если вы ещё не выполняли полный цикл, в разделе [Руководство](../01_GettingStarted/04_Tutorial.md) продемонстрирована работа этих
примитивов на практике. Вы также можете ознакомиться с разделом [Подключение кодовой базы](../01_GettingStarted/03_Onboarding.md)
для подготовки ваших репозиториев к параллельным рабочим деревьям.
