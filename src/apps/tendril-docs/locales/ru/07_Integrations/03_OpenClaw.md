# OpenClaw

## Обзор

Tendril отслеживает **папку Inbox** на появление новых markdown-файлов и автоматически преобразует их в [планы](../02_Concepts/01_Plans.md). Это обеспечивает простую интеграцию на основе файлов для внешних инструментов, таких как OpenClaw, или пользовательских скриптов, записывающих файлы на диск.

## Расположение папки Inbox

```
$TENDRIL_HOME/Inbox/
```

Подробные сведения о домашней директории Tendril и конфигурации см. в разделе [Установка и настройки](../03_Configuration/01_Setup.md). Служба отслеживания файловой системы Tendril мониторит эту директорию на наличие новых файлов `.md`.

## Формат файла

Поместите файл markdown (`.md`) с опциональным YAML frontmatter:

```markdown
---
project: ProjectName
sourcePath: optional/path/to/code
---

Describe the plan here. This text becomes the plan description
and is passed to the [CreatePlan promptware](../02_Concepts/02_Promptwares.md).
```

| Поле         | Обязательно | Описание                                   |
| ------------ | ----------- | ------------------------------------------ |
| `project`    | Нет         | Имя целевого проекта (по умолчанию `Auto`) |
| `sourcePath` | Нет         | Подсказка пути к связанному исходному коду |

Содержимое после frontmatter становится описанием плана.

> [!NOTE]
> Если полностью опустить frontmatter, все содержимое файла будет использовано в качестве описания плана с настройками по умолчанию.

## Жизненный цикл файла

1. **Добавление** файла `.md` в папку Inbox
2. **Обработка** — файл переименовывается в `.md.processing` на время обработки
3. **Завершение** — файл удаляется после успешного создания плана

## Восстановление

Если Tendril перезапускается во время обработки, любые файлы `.md.processing` автоматически восстанавливаются обратно в `.md` и обрабатываются повторно при запуске.

## Настройка интеграции с OpenClaw

Настройте OpenClaw так, чтобы он сохранял свои выходные данные в виде файлов markdown в папку Inbox Tendril. Каждый файл преобразуется в отдельный план:

1. Установите директорию вывода на `$TENDRIL_HOME/Inbox/`
2. Используйте формат markdown с YAML frontmatter для указания целевого проекта
3. Tendril автоматически подхватывает новые файлы — опрос или вызовы API не требуются
