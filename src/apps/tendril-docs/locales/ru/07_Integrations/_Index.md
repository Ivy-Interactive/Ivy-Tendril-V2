# Интеграции

Подключайте Tendril к внешним инструментам и сервисам для оптимизации процесса разработки и автоматизации [выполнения планов](../02_Concepts/01_Plans.md).

- [GitHub](01_Github.md) — импорт задач, автоматическое создание pull request'ов и синхронизация статуса PR с [GitHub](https://github.com).
- [Jam.dev](02_JamDev.md) — автоматическое создание планов из отчетов об ошибках через вебхук API входящих сообщений [Jam.dev](https://jam.dev).
- [OpenClaw](03_OpenClaw.md) — файловый импорт планов из внешних инструментов, таких как OpenClaw, через папку входящих файлов (drop folder) Tendril Inbox.
