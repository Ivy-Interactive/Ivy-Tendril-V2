# Добро пожаловать в Ivy Tendril

[![Ivy Tendril за две минуты: смотреть на YouTube](../assets/yt-thumbnail-in-two-minutes-2.png)](https://youtu.be/_KVG1NnAj-8)

## Концепция

В Tendril работа организована в виде [**планов**](../02_Concepts/01_Plans.md) — структурированных, доступных для проверки единиц работы.
Вместо непрозрачного «чёрного ящика», выдающего непроверенный код, Tendril проводит ваш план через определённый
[жизненный цикл](../02_Concepts/03_Lifecycle.md) с использованием [**промптваров**](../02_Concepts/02_Promptwares.md):
изолированных специализированных агентов рабочих процессов, каждый из которых отвечает за один этап. Будь то составление плана,
внесение изменений в параллельных рабочих деревьях (worktrees), прохождение проверок или открытие pull request — вы сохраняете
полный контроль и видимость. Tendril не просто дополняет строки кода в редакторе, он координирует весь автономный
процесс разработки.

## Ключевые возможности

- **Параллельные рабочие деревья (Parallel worktrees)** — каждый агент работает в изолированном [рабочем дереве Git](https://git-scm.com/docs/git-worktree),
  что позволяет одновременно выполнять несколько планов без загрязнения веток и конфликтов рабочего каталога.
- **Туннелирование для удалённой и мобильной работы** — безопасный доступ к локальному демону через
  [Cloudflare Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/),
  позволяющий отслеживать прогресс и направлять агентов прямо со смартфона или удалённого браузера.
- **Голосовой и расширенный ввод** — надиктовывайте требования с помощью встроенной транскрипции [OpenAI Whisper](https://github.com/openai/whisper)
  или прикрепляйте логи терминала, спецификации markdown и файлы дизайна в качестве контекста.
- **Аннотации к планам** — комментируйте черновик плана прямо в интерфейсе; Tendril передаёт ваши замечания в
  [UpdatePlan](../02_Concepts/02_Promptwares.md) для обновления спецификации.
- **Ревью кода с этапами верификации** — изучайте диффы git, проверяйте результаты автоматических тестов (`Cargo`,
  `pnpm`, линтинг, форматирование) и одобряйте только проверенные изменения.
- **Интеграция с GitHub и входящими сообщениями** — автоматическое превращение входящих issue [GitHub](https://github.com) и
  отчётов об ошибках [Jam.dev](https://jam.dev) в планы через вебхуки.

## Архитектура

Tendril состоит из трёх основных компонентов, работающих локально на вашем компьютере:

- **Десктопное приложение** на базе [Tauri 2](https://tauri.app) — высокопроизводительная нативная оболочка,
  содержащая фронтенд на [React](https://react.dev).
- **Серверный демон** на языке [Rust](https://www.rust-lang.org) (`tendril run` / `tendril serve`),
  предоставляющий REST и WebSocket API. Десктопное приложение автоматически запускает и контролирует демона в
  фоновом режиме.
- **CLI** (`tendril`), который подключается к тому же демону и использует общее хранилище данных. Любое действие,
  доступное в десктопном приложении, можно выполнить через командную строку.

Состояние хранится исключительно локально:

- Локальная база данных [SQLite](https://www.sqlite.org) в `$TENDRIL_HOME/tendril.db` фиксирует задания, расходы и
  телеметрию.
- Файловое хранилище в `$TENDRIL_HOME/Plans/` хранит файлы планов, ревизии, аннотации, логи и
  отчёты о верификации в виде прозрачных документов YAML и Markdown.

> [!NOTE]
> Значение `$TENDRIL_HOME` по умолчанию: `~/.tendril`. См. раздел [Установка](02_Installation.md) для настройки пользовательского пути.

Ваш исходный код никогда не покидает локальный компьютер. Единственный исходящий сетевой трафик — это прямые API-запросы
настроенного кодинг-агента (например, к Anthropic, OpenAI или Google) и опциональные туннели Cloudflare,
запускаемые вами явно.

Поддерживаемые кодинг-агенты:

- [Claude Code](https://code.claude.com/docs) (`claude`)
- [OpenAI Codex](https://openai.com) (`codex`)
- [GitHub Copilot](https://github.com/features/copilot) (`copilot`)
- [Google Gemini](https://ai.google.dev) (`gemini`)
- [OpenCode](https://opencode.ai) (`opencode`)
- Antigravity (`antigravity` / `agy`)
- [Cursor](https://www.cursor.com) (`cursor`)
- Apple Foundation Models (`apple` через локальный `fm`)

## Почему Tendril?

В [Ivy Interactive](https://ivy.app) мы протестировали множество мультиагентных архитектур для автономного кодинга.
Хотя отдельные консольные агенты были мощными, управление десятком вкладок терминала и ручной просмотр несохранённых диффов
быстро заходили в тупик.

Tendril привносит структуру в агентную разработку. Благодаря нашей архитектуре [промптваров](../02_Concepts/02_Promptwares.md)
агенты накапливают специфическую память проекта между запусками, изучая идиомы кодовой базы и
предотвращая повторные ошибки. Делая основой процесса долговечные
[планы](../02_Concepts/01_Plans.md), мы сохраняем контроль за разработчиком-человеком, в то время как автономные агенты выполняют
всю тяжёлую работу по реализации.
