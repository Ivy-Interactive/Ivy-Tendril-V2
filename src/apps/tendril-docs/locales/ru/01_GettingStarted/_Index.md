# Начало работы

Шесть страниц в порядке чтения. Первые две помогут запустить Tendril, следующие две — настроить его для _автономной_ работы с вашим репозиторием, в чём и заключается главная ценность.

- [Введение](01_Introduction.md) — что такое Tendril, как он устроен и почему работает именно так.
- [Установка](02_Installation.md) — предварительные требования, сборка из исходного кода и расположение конфигурационных файлов.
- [Подключение кодовой базы](03_Onboarding.md) — чек-лист подготовки системы и репозитория перед запуском первого реального плана.
- [Руководство](04_Tutorial.md) — полный цикл: регистрация проекта, создание плана, его выполнение, проверка диффа и открытие pull request.
- [Получение помощи](05_GettingHelp.md) — Discord, задачи на GitHub и необходимые данные для отчёта об ошибке.
- [Устранение неполадок](06_Troubleshooting.md) — симптомы проблем и способы их устранения по разделам.

После ознакомления с этими страницами раздел [Концепции](../02_Concepts/_Index.md) раскроет базовую модель: [планы](../02_Concepts/01_Plans.md), [промптвары](../02_Concepts/02_Promptwares.md) и [жизненный цикл заданий](../02_Concepts/03_Lifecycle.md).
