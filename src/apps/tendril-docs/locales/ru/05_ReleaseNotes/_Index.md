Отслеживайте изменения, новые возможности, улучшения производительности и исправления ошибок для каждого релиза Tendril.

В этом разделе представлен хронологический журнал обновлений десктопного приложения Tendril, утилит CLI, архитектуры демона и среды выполнения агентов:

- [Примечания к выпуску](01_ReleaseNotes.md) — подробная история версий и список изменений для выпусков Tendril с особым вниманием к знаковому переходу на архитектуру [Tendril v2](#) на базе [Rust](https://www.rust-lang.org), [Tauri v2](https://tauri.app), [Vite+](https://viteplus.dev), [React](https://react.dev) и [SQLite](https://www.sqlite.org).
