# Дашборд

Дашборд — это основной операционный центр Tendril, обеспечивающий видимость конвейера разработки, расходов на агентов, скорости доставки и активных заданий по всем проектам в реальном времени.

## Заголовок и обзор конвейера

В верхней части Дашборда отображаются текущая дата, приветствие по времени суток и **Монитор процессов** (`TendrilProcessViewer`):

- **Черновики (Drafts)** — общее количество планов в состоянии `Draft`, ожидающих доработки или выполнения.
- **Выполняемые задания (In-Flight Jobs)** — счётчик активных заданий агентов в реальном времени с разбивкой по фазам промптваров (**Создание**, **Обновление**, **Выполнение**, **Повтор** и **Создание PR**).
- **Ревью (Review)** — планы с завершённым выполнением, ожидающие проверки и одобрения разработчиком.
- **Завершённые и сбойные (Completed & Failed)** — суммарное количество завершённых заданий.

Клик по любому этапу в мониторе процессов выполняет переход в соответствующий раздел ([Планы](03_Plans.md), [Задания](04_Jobs.md) или [Ревью](02_Review.md)). Кнопка **+ New Plan** также доступна прямо из монитора процессов.

## Ключевые показатели эффективности (KPI)

Четыре основные карточки KPI суммируют скорость и экономическую эффективность разработки:

| Метрика                  | Значение                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------- |
| **Features Shipped**     | Общее количество завершённых планов и смерженных pull request во всех проектах.     |
| **Avg cost per Feature** | Средняя стоимость в долларах, затраченная на выпуск одной готовой функции.          |
| **Forecast This Month**  | Прогнозируемые месячные расходы, рассчитанные на основе темпа за последние 30 дней. |
| **Avg Cost/Plan**        | Средняя стоимость одного плана с учётом входных, выходных и закэшированных токенов. |

### Панели детализации (Breakdown Blades)

Клик по любой карточке KPI выдвигает панель глубокой детализации (`BladeContainer`):

- **Детализация по проектам и агентам** — показывает, на какие проекты или кодинг-агенты приходится наибольшая доля расхода токенов и затрат.
- **Таблица детализации по планам** — детальный аудит по каждому плану с указанием названия, длительности выполнения, количества токенов (входные, выходные, чтение из кэша, рассуждения) и общей стоимости.
- **Прямая навигация** — клик по любому плану в панели детализации открывает его полную спецификацию.

## 28-дневный дневной тренд

Карточка **Daily Trend** отображает ежедневную активность выполнения и расход токенов за 28-дневный период:

- **Столбчатая диаграмма** — ежедневные суммы затрат и активности.
- **7-дневное скользящее среднее** — сглаживающая кривая поверх графика для нивелирования дневных колебаний и отображения траектории разработки.

## Pull Requests

Карточка **Pull Requests** предоставляет:

- **Еженедельный темп PR** — столбчатая диаграмма принятых pull request за скользящее 6-недельное окно.
- **Недавние слияния** — быстрый список недавно смерженных pull request на [GitHub](https://github.com) со значками проектов и ссылками на раздел [Pull Requests](06_PullRequests.md).

## Активные задания

Карточка **Active Jobs** отображает до восьми одновременно выполняемых заданий агентов в реальном времени:

- **Текущий статус** — отображает бейдж статуса (`Running`, `Pending` или `Blocked`).
- **Целевой план и промптвар** — определяет название плана или конкретный тип [Промптвара](../02_Concepts/02_Promptwares.md) (`CreatePlan`, `ExecutePlan`, `UpdatePlan` и др.).
- **Прямая проверка** — клик по любому заданию открывает терминал с потоковым выводом в приложении [Задания](04_Jobs.md).

## Учёт затрат и токенов

Каждое выполнение промптвара добавляет строку в постоянный файл `costs.csv` плана, расположенный в `$TENDRIL_HOME/plans/<planId>/costs.csv`.

Tendril синхронизирует эти записи CSV со своей базой данных [SQLite](https://www.sqlite.org) для расчёта стоимости с использованием актуальных цен [models.dev](https://models.dev) (включая входные токены, токены генерации, чтение/запись кэша промптов и токены рассуждений). Все графики отражают эти согласованные показатели в цветах проектов, заданных в [Настройке проектов](../03_Configuration/02_Projects.md).
