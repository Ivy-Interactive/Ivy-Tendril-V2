# Задачи

Приложение «Задачи» (Jobs) — это монитор выполнения в реальном времени и журнал аудита истории в Tendril. Каждый вызов [Promptware](../02_Concepts/02_Promptwares.md) (`CreatePlan`, `ExecutePlan`, `UpdatePlan`, `CreatePr`, `SplitPlan` и т. д.) выполняется как асинхронная задача, отслеживаемая здесь.

## Обзор и прогресс статусов

В верхней части представления «Задачи» **многоуровневый индикатор выполнения** (`StackedProgress`) отображает распределение состояний задач в реальном времени:

- **Running** (синий) — Активно выполняющиеся процессы агентов.
- **Completed** (зеленый) — Успешно завершенные выполнения.
- **Failed** (красный) — Запуски, завершившиеся с ошибками или не прошедшие проверку.
- **Blocked** (янтарный) — Задачи, ожидающие зависимостей, лимитов параллелизма или подтверждения оператора.
- **Pending** (приглушенный) — Задачи в очереди, ожидающие доступных слотов агентов.

Элементы массового управления выполнением в заголовке позволяют операторам при необходимости выполнять команды **Stop All Queued** или **Stop All**, а также пакетом очищать строки истории через выпадающее меню **Clear** (`Clear Completed`, `Clear Failed` или `Clear All`).

## Таблица задач

Таблица использует бесконечную прокрутку с сортировкой и фильтрацией на стороне сервера (демона):

| Столбец     | Описание                                                            | Взаимодействие                                                                                                |
| ----------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Id**      | Числовой идентификатор задачи (например, `00042`).                  | Нажмите на заголовок для сортировки по новизне.                                                               |
| **Plan Id** | Идентификатор целевого плана.                                       | Нажмите для прямого перехода к плану в [Планы](03_Plans.md).                                                  |
| **Status**  | Бейдж текущего статуса задачи.                                      | Цветовая кодировка по состоянию.                                                                              |
| **Type**    | Идентификатор promptware (например, `ExecutePlan`).                 | Сортировка по promptware.                                                                                     |
| **Project** | Бейдж проекта.                                                      | Оформлен цветом проекта из [Настройка проекта](../03_Configuration/02_Projects.md).                           |
| **Output**  | Состояние выполнения агента (`running`, `done`, `idle`).            | **Нажмите, чтобы открыть панель вывода в реальном времени** (`JobSessionView`) с потоковым выводом терминала. |
| **Tokens**  | Общее количество потребленных токенов.                              | **Нажмите, чтобы открыть панель стоимости и токенов** (`JobCostSheet`).                                       |
| **Cost**    | Рассчитанная стоимость выполнения в USD.                            | **Нажмите, чтобы открыть панель стоимости и токенов**.                                                        |
| **Timer**   | Таймер прошедшего времени или зафиксированная длительность запуска. | Отображает длительность в реальном времени.                                                                   |
| **Date**    | Временная метка запуска задачи.                                     | Хронологическая сортировка.                                                                                   |

## Панели и всплывающие окна

Нажатие на ячейки или действия со строками открывает контекстные всплывающие панели прямо поверх таблицы без потери текущей позиции:

### Панель вывода в реальном времени (`JobSessionView`)

Нажатие на ячейку **Output** открывает окно просмотра агента в реальном времени. Вы видите потоковый вывод `stdout`/`stderr` терминала от агента в реальном времени (логи сборки, вывод тестов, вызовы инструментов и рассуждения агента), а не просто стандартный индикатор загрузки.

### Панель стоимости и токенов (`JobCostSheet`)

Нажатие на ячейку **Tokens** или **Cost** открывает подробную детализацию расходов:

- **Input Tokens** — Входные токены промпта и контекста, отправленные модели.
- **Output Tokens** — Токены, сгенерированные моделью.
- **Cache Read Tokens** — Токены, полученные из кэша промптов (экономят стоимость и снижают задержку).
- **Cache Write Tokens** — Токены, записанные в кэш промптов провайдера.
- **Reasoning Tokens** — Токены, затраченные на внутренние модели рассуждений (например, OpenAI o1/o3 или расширенное мышление Anthropic).
- **Cost Calculation** — Расчет стоимости в валюте, сверенный с тарифами на [models.dev](https://models.dev).

### Панель полного промпта

Нажатие на текст **Prompt** открывает полный, несокращенный промпт, отправленный агенту, с полной подсветкой синтаксиса.

## Меню действий со строкой

В каждой строке задачи доступно меню действий (`...`):

| Действие        | Доступность            | Эффект                                                                                                                                                                           |
| --------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stop**        | Активные задачи        | Немедленно завершает работающий процесс агента. Рабочее дерево [Git](https://git-scm.com) сохраняется, чтобы вы могли возобновить работу или просмотреть промежуточный прогресс. |
| **Force Start** | Заблокированные задачи | Обходит ограничения параллелизма или блокировки зависимостей для немедленного запуска задачи.                                                                                    |
| **Debug**       | Все задачи             | Открывает **панель отладки задачи** (`JobDebugSheet`), предоставляющую доступ во вкладках к Job Log, Job Prompt, Raw Output Log и Eventwire Log с кнопками «Open in Editor».     |
| **Delete**      | Completed / Failed     | Безвозвратно удаляет запись о задаче из истории с подтверждением.                                                                                                                |
