# Icebox (Холодильник)

Icebox — это выделенный бэклог и буферное хранилище Tendril для отложенных, низкоприоритетных или будущих инженерных планов. Откладывание планов позволяет держать активную очередь черновиков [Plans](03_Plans.md) сфокусированной на приоритетах текущего спринта, не теряя при этом результатов исследований, обсуждений или составленных спецификаций (см. [Plan Lifecycle](../02_Concepts/03_Lifecycle.md)).

## Откладывание планов

План можно отложить в любой момент, пока он находится в состоянии `Draft` или `Blocked`:

- В приложении [Plans](03_Plans.md) выберите **Shelve to Icebox** в меню действий.
- Tendril обновит статус плана на `Icebox`.
- Каталог плана по пути `$TENDRIL_HOME/plans/<planId>/`, его версионированные ревизии и записи о затратах полностью сохраняются на диске (см. [CLI Plan Management](../09_Advanced/01_CLI/01_Plan.md)).

## Просмотр и фильтрация

Приложение Icebox предоставляет удобные инструменты поиска и фильтрации по вашему бэклогу:

- **Строка поиска (Search Bar)** — фильтрация планов по ключевым словам в названии или числовому `#ID` плана.
- **Фильтр проектов (Project Filter)** — ограничение списка отложенных планов конкретным проектом, настроенным в [Project Setup](../03_Configuration/02_Projects.md).
- **Фильтр уровней (Level Filter)** — фильтрация планов по уровню сложности (например, L1, L2, L3, настроенным в [Setup & Settings](../03_Configuration/01_Setup.md#in-app-settings)).

## Карточки планов и действия

Каждый отложенный план отображается в виде карточки с тегом `#ID`, названием, бейджем проекта, бейджем уровня сложности и индикаторами верификации:

| Действие         | Элемент управления         | Результат                                                                                                                                                                                                                      |
| ---------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Inspect Plan** | Клик по заголовку карточки | Открывает рабочую область плана в [Plans](03_Plans.md) для просмотра полной спецификации, метаданных или предыдущих ревизий.                                                                                                   |
| **Thaw**         | Кнопка с иконкой пламени   | Оптимистично переводит план из `Icebox` обратно в `Draft`. План немедленно покидает Icebox и возвращается в активную очередь [Plans](03_Plans.md), готовый к выполнению через [ExecutePlan](../02_Concepts/02_Promptwares.md). |
| **Delete**       | Кнопка с иконкой корзины   | Открывает `DeletePlanDialog` для безвозвратного удаления папки плана, ревизий и записей в базе данных.                                                                                                                         |
