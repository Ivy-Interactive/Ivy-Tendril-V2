# Пулл-реквесты

Приложение «Пулл-реквесты» обеспечивает межпроектное отслеживание всех пулл-реквестов [GitHub](https://github.com), созданных на основе утвержденных планов Tendril. Оно предоставляет единый дашборд для мониторинга открытых, объединенных (merged) или закрытых PR, а также расхода токенов и затрат, связанных с каждой реализацией.

## Жизненный цикл и рабочий процесс PR

1. **Утверждение** — как только план завершает выполнение и утверждается на этапе [Review](02_Review.md), нажатие кнопки **Create Pull Request** запускает promptware `CreatePr` (см. [Promptwares](../02_Concepts/02_Promptwares.md)).
2. **Создание** — Tendril использует [GitHub CLI](https://cli.github.com) (`gh`), чтобы отправить (push) изолированную ветку рабочего дерева [Git](https://git-scm.com) и открыть пулл-реквест на [GitHub](https://github.com) со сгенерированной ИИ сводкой (см. [GitHub Integration](../07_Integrations/01_Github.md)).
3. **Отслеживание** — пулл-реквест связывается с планом и отслеживается в этом представлении до момента слияния или закрытия.

## Таблица пулл-реквестов

В таблице перечислены все пулл-реквесты, зафиксированные по всем вашим проектам:

| Колонка        | Описание                                                   | Взаимодействие                                                                               |
| -------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **Plan**       | `#ID` и название плана.                                    | Нажмите, чтобы открыть всплывающую панель предпросмотра с полной спецификацией плана.        |
| **Project**    | Бейдж проекта.                                             | Отображает цвет проекта, заданный в [Project Setup](../03_Configuration/02_Projects.md).     |
| **Status**     | Бейдж статуса (`Open`, `Merged`, `Closed` или `Unknown`).  | При наведении курсора во всплывающей подсказке отображается время последней проверки GitHub. |
| **PR**         | Номер пулл-реквеста на GitHub (например, `#84`).           | Нажмите, чтобы открыть пулл-реквест на [GitHub](https://github.com) в браузере по умолчанию. |
| **Tokens**     | Суммарное количество токенов, израсходованных планом.      | Компактное отображение количества токенов (например, `450K`, `1.2M`).                        |
| **Cost**       | Общая стоимость в долларах США (USD) для всех задач плана. | Отформатированная сумма расходов в валюте.                                                   |
| **Repository** | Целевой репозиторий GitHub (`owner/repo`).                 | Полный путь к целевому репозиторию.                                                          |
| **Branch**     | Имя ветки Git.                                             | Исходная ветка в репозитории.                                                                |

## Фильтрация и синхронизация

- **Фильтры по статусу** — используйте переключатель статусов над таблицей для фильтрации по `Open`, `Merged`, `Closed` или `Unknown`.
- **Поиск** — фильтруйте строки в реальном времени по ID плана, названию, имени проекта, репозиторию или имени ветки.
- **Повторная синхронизация с GitHub** — нажмите кнопку **Resync**, чтобы выполнить проход синхронизации (`gh pr list`) по настроенным репозиториям. Tendril сообщит обо всех недоступных, неавторизованных или ограниченных по лимиту запросов репозиториях.

> [!NOTE]
> Объединенные (merged) пулл-реквесты имеют терминальный статус и повторно не проверяются во время периодических проходов синхронизации.

## Действия со строками

В каждой строке пулл-реквеста доступны четыре быстрых действия:

- **View Plan** — переходит в рабочее пространство с подробной информацией о плане в приложении [Plans](03_Plans.md).
- **Follow Up** — открывает диалоговое окно New Plan с предварительно заполненными ссылками на репозиторий, проект и ветку, что позволяет легко создать последующие задачи, исправления ошибок или доработки в [Plans](03_Plans.md).
- **Open PR** — открывает пулл-реквест на [GitHub](https://github.com) в вашем веб-браузере.
- **Resync** — обновляет статус из GitHub для конкретного репозитория.
