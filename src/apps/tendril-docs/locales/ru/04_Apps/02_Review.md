# Ревью

Приложение Ревью (Review) — это главный рубеж контроля качества в Tendril. Когда агент завершает выполнение плана через `ExecutePlan` (см. [Промптвары](../02_Concepts/02_Promptwares.md)), изолированное рабочее дерево [Git](https://git-scm.com) сохраняется и отображается здесь для проверки разработчиком, верификации и принятия решений. Ничего не сливается и не попадает в вашу основную ветку без прямого одобрения оператора.

## Очередь ревью (Review Queue)

Боковая панель содержит список всех планов, требующих внимания разработчика (планы со статусом `Review` или `Failed`):

- **Бейджи** — каждая строка отображает номер плана `#ID`, бейдж проекта и статус [Верификации](../03_Configuration/01_Setup.md#верификации):
  - `Verified` (зелёный) — все обязательные проверки верификации пройдены успешно.
  - `Unverified` (предупреждение) — одна или несколько проверок завершились сбоем либо ещё не запускались.
  - Индикатор состояния (например, `Failed`) для быстрого обнаружения выполнений, требующих отладки.
- **Горячие клавиши** — используйте стрелки `ArrowLeft` и `ArrowRight` для быстрого перемещения между планами в очереди ревью.

## Рабочая область ревью

Основное рабочее пространство отображает реализацию плана и инструменты инспекции:

- **Обзор плана и комментарии** — просмотр спецификации плана с возможностью добавления построчных комментариев (`DraftComment`) для точной обратной связи.
- **Панель действий ревью (Review Actions Bar)** — действия ревью, настроенные для проекта (в секции `reviewActions` в [Настройке проектов](../03_Configuration/02_Projects.md)), отображаются в виде кнопок быстрого доступа на панели инструментов (например, `Run E2E`, `Smoke Test`).
- **Полная спецификация и дифф** — действие в меню рабочей области, открывающее страницу плана в приложении [Планы](03_Plans.md) для изучения многоревизионных диффов, графа коммитов git worktree и созданных артефактов.
- **Встроенный чат по плану** — используйте встроенную панель `PlanChatPanel`, чтобы задать агенту вопросы, уточнить логику выполнения или скорректировать детали перед утверждением.

## Действия по триажу

| Действие                    | Элемент управления                 | Результат                                                                                                                                                                                             |
| --------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Create Pull Request**     | Основная кнопка (CTA)              | Создаёт pull request на [GitHub](https://github.com) через [GitHub CLI](https://cli.github.com) (`gh`), связывает его с планом в [Pull Requests](06_PullRequests.md) и помечает план как `Completed`. |
| **Push to PR**              | Основная кнопка (если PR есть)     | Отправляет новые коммиты из рабочего дерева в существующую ветку pull request.                                                                                                                        |
| **Request Changes**         | Кнопка с иконкой и бейджем         | Открывает диалог `SuggestChangesDialog` для отправки комментариев, запуская задание `UpdatePlan` в [Заданиях](04_Jobs.md) в существующем рабочем дереве.                                              |
| **Accept Partial Delivery** | Вторичная кнопка                   | Открывает `PartialDeliveryDialog` для принятия работающей части результата с сохранением оставшихся задач на будущее.                                                                                 |
| **Reset to Draft**          | Дополнительное меню                | Открывает `ResetToDraftDialog` для возврата плана в статус `Draft` в приложении [Планы](03_Plans.md) для изменения масштаба.                                                                          |
| **Delete Plan**             | Дополнительное меню (деструктивно) | Открывает `DeletePlanDialog` для безвозвратного удаления плана и очистки его изолированного рабочего дерева.                                                                                          |
