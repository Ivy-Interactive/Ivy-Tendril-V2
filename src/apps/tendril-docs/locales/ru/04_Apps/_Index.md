# Приложения

Tendril предоставляет специализированные десктопные приложения и разделы, предназначенные для различных этапов планирования и выполнения ПО в рамках [Жизненного цикла планов](../02_Concepts/03_Lifecycle.md):

- [Дашборд (Dashboard)](01_Dashboard.md) — операционный обзор, включающий воронку планов, метрики KPI с детализацией, 28-дневный дневной тренд и мониторинг активных [Заданий](04_Jobs.md).
- [Ревью (Review)](02_Review.md) — очередь решений по готовым планам, ожидающим одобрения, логи верификаций, встроенные запросы изменений, действия ревью проекта и создание pull request на [GitHub](https://github.com).
- [Планы (Plans)](03_Plans.md) — рабочее пространство для составления и доработки планов с диффами между ревизиями, встроенным чатом, проверками верификации и управлением выполнением [Промптваров](../02_Concepts/02_Promptwares.md).
- [Задания (Jobs)](04_Jobs.md) — монитор выполнения и журнал аудита с потоковой трансляцией вывода терминала, детализацией токенов/затрат, панелями отладки и управлением процессами.
- [Ледник (Icebox)](05_Icebox.md) — зона отложенных и замороженных планов с полнотекстовым поиском, фильтрацией по проектам и уровням сложности, а также разморозкой в активные [Планы](03_Plans.md) в один клик.
- [Pull Requests](06_PullRequests.md) — межпроектное отслеживание pull request на [GitHub](https://github.com) с фоновой синхронизацией статусов через [GitHub CLI](https://cli.github.com), метриками расходов и генерацией последующих планов.
- [Рекомендации (Recommendations)](07_Recommendations.md) — автоматические предложения по улучшению кодовой базы и покрытию тестами с принятием в один клик и созданием задач на [GitHub](https://github.com).

Инструкции по настройке проектов и агентов, обеспечивающих работу этих приложений, приведены в разделах [Установка и настройки](../03_Configuration/01_Setup.md) и [Настройка проектов](../03_Configuration/02_Projects.md).
