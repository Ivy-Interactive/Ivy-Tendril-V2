# Intégrations

Connectez Tendril à des outils et services externes pour optimiser votre flux de développement et automatiser [l'exécution de plans](../02_Concepts/01_Plans.md).

- [GitHub](01_Github.md) — importation d'issues, création automatique de pull requests et synchronisation de l'état des PR avec [GitHub](https://github.com).
- [Jam.dev](02_JamDev.md) — création automatisée de plans à partir de rapports de bugs via le webhook d'API de boîte de réception de [Jam.dev](https://jam.dev).
- [OpenClaw](03_OpenClaw.md) — ingestion de plans basée sur des fichiers depuis des outils externes comme OpenClaw via le dossier de dépôt Inbox de Tendril.
