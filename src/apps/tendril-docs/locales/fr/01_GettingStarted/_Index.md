# Premiers pas

Six pages, par ordre de lecture. Les deux premières permettent de mettre Tendril en service ; les deux suivantes le font fonctionner
de façon _autonome_ sur votre propre dépôt, là où réside toute la valeur.

- [Introduction](01_Introduction.md) — ce qu'est Tendril, sa conception et les raisons de son fonctionnement.
- [Installation](02_Installation.md) — prérequis, compilation depuis les sources et emplacement de la configuration.
- [Intégration d'une base de code](03_Onboarding.md) — la liste de contrôle pour votre machine et votre dépôt
  avant de lancer votre premier vrai plan.
- [Tutoriel](04_Tutorial.md) — une boucle complète : enregistrer un projet, créer un plan, l'exécuter, examiner
  le diff et ouvrir une pull request.
- [Obtenir de l'aide](05_GettingHelp.md) — Discord, issues GitHub et éléments à joindre à un rapport de bogue.
- [Dépannage](06_Troubleshooting.md) — symptômes et correctifs, par domaine.

Après ces pages, [Concepts](../02_Concepts/_Index.md) détaille le modèle sous-jacent :
les [plans](../02_Concepts/01_Plans.md), les [promptwares](../02_Concepts/02_Promptwares.md) et le
[cycle de vie des jobs](../02_Concepts/03_Lifecycle.md).
