# 快速入门

按阅读顺序编排的 6 个页面。前两页帮助您运行 Tendril；接下来的两页帮助您针对自己的代码仓库实现*无人值守*运行，这正是其核心价值所在。

- [简介](01_Introduction.md) — Tendril 是什么、它是如何构建的，以及为什么采用这样的工作机制。
- [安装](02_Installation.md) — 前置准备条件、源码构建，以及配置文件的存放位置。
- [代码库准备](03_Onboarding.md) — 在运行第一个正式计划之前需要逐项检查的机器与仓库清单。
- [教程](04_Tutorial.md) — 完整闭环流程：注册项目、创建计划、执行计划、审查 diff、提交 PR。
- [获取帮助](05_GettingHelp.md) — Discord、GitHub issues 以及缺陷报告中需要附带的信息。
- [故障排除](06_Troubleshooting.md) — 按领域划分的常见问题排查与修复方法。

完成上述内容后，[核心概念](../02_Concepts/_Index.md) 将为您解释底层模型：
[计划](../02_Concepts/01_Plans.md)、[Promptware](../02_Concepts/02_Promptwares.md) 和 [任务生命周期](../02_Concepts/03_Lifecycle.md)。
