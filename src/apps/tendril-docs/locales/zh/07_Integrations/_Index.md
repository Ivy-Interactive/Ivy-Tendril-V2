# 集成

将 Tendril 与外部工具和服务连接，以简化您的开发工作流并实现[计划执行](../02_Concepts/01_Plans.md)的自动化。

- [GitHub](01_Github.md) — Issue 导入、自动创建 Pull Request 以及与 [GitHub](https://github.com) 的 PR 状态同步。
- [Jam.dev](02_JamDev.md) — 通过 [Jam.dev](https://jam.dev) 收件箱 API Webhook 根据缺陷报告自动创建计划。
- [OpenClaw](03_OpenClaw.md) — 通过 Tendril Inbox 投放文件夹从 OpenClaw 等外部工具基于文件摄取计划。
