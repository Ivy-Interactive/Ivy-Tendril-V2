# CLI

Tendril 命令行界面提供了用于直接在终端中管理计划、项目、数据库和守护进程的命令。

- [CLI 概览](00_Overview.md) — 全局选项、环境变量以及常用故障排查命令。
- [plan](01_Plan.md) — 创建、列出、更新和验证计划、工作区 (worktree)、修订版本和验证门禁。
- [project](02_Project.md) — 配置项目、代码仓库、构建依赖项、审查动作、MCP 服务端及技能。
- [verification](03_Verification.md) — 定义和管理可复用的全局验证检查。
- [数据库](04_Database.md) — 架构版本、迁移、数据库重置、完整性检查及清理 (vacuum)。
- [其他命令](05_Other.md) — Promptware 执行、任务跟踪、聊天会话、后台服务注册及实用工具。
- [config](06_Config.md) — 读取并更新保存在 `config.yaml` 中的顶层配置。
- [vault](07_Vault.md) — 连接团队配置库 (Vault)、发现共享代码仓库，以及导入或发布项目。
