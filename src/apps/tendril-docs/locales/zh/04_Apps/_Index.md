# 应用

Tendril 提供了专为软件规划与执行 [任务生命周期](../02_Concepts/03_Lifecycle.md) 各个阶段设计的专用桌面应用和视图：

- [仪表盘](01_Dashboard.md) — 运营概览，包含计划流水线流程、带下钻分析抽屉的 KPI 指标、28 天每日趋势以及活动 [任务](04_Jobs.md) 监控。
- [审查](02_Review.md) — 等待批准的已完成计划决策队列，提供验证日志、内联修改请求、项目审查操作以及 [GitHub](https://github.com) Pull Request 创建。
- [计划](03_Plans.md) — 计划起草与完善工作区，具备多版本 diff 对比、内嵌 Chat、验证门禁以及 [Promptware](../02_Concepts/02_Promptwares.md) 执行控制。
- [任务](04_Jobs.md) — 执行监控器与审计日志，提供实时终端输出流、Token/成本明细、调试抽屉与进程管理。
- [待办箱](05_Icebox.md) — 延期与搁置计划的积压暂存区，支持全文搜索、项目和层级过滤，以及一键解冻至活跃 [计划](03_Plans.md)。
- [Pull Requests](06_PullRequests.md) — 跨项目的 [GitHub](https://github.com) Pull Request 追踪，支持通过 [GitHub CLI](https://cli.github.com) 进行后台状态同步、支出指标统计与后续跟进计划生成。
- [改进建议](07_Recommendations.md) — 针对代码库优化和缺失测试覆盖率的自动化建议，支持一键接受与创建 [GitHub](https://github.com) Issue。

有关为这些应用提供支持的项目与智能体配置说明，请参阅 [设置与配置](../03_Configuration/01_Setup.md) 与 [项目设置](../03_Configuration/02_Projects.md)。
