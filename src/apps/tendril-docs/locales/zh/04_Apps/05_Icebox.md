# 待办箱

待办箱 (Icebox) 是 Tendril 专用于延期、低优先级或未来工程计划的积压与搁置空间。搁置计划可以使活跃的 [计划](03_Plans.md) 草稿队列专注于当前迭代的优先级，同时不会丢失前期的研究、讨论或已起草的规范（请参阅 [任务生命周期](../02_Concepts/03_Lifecycle.md)）。

## 搁置计划

处于 `Draft` 或 `Blocked` 状态的计划可以随时被搁置：

- 在 [计划](03_Plans.md) 应用中，从操作菜单中选择 **Shelve to Icebox**。
- Tendril 会将该计划的状态更新为 `Icebox`。
- 位于 `$TENDRIL_HOME/plans/<planId>/` 下的计划目录、其版本化的修订历史以及成本记录在磁盘上均得到完整保留（请参阅 [CLI 计划管理](../09_Advanced/01_CLI/01_Plan.md)）。

## 浏览与筛选

待办箱应用为您积压的计划提供专注的搜索与筛选功能：

- **搜索栏** — 按标题关键字或数字计划 `#ID` 筛选计划。
- **项目筛选器** — 将搁置的计划缩小至在 [项目设置](../03_Configuration/02_Projects.md) 中配置的特定项目。
- **层级筛选器** — 按复杂度层级（例如在 [设置与配置](../03_Configuration/01_Setup.md#in-app-settings) 中配置的 L1、L2、L3）筛选计划。

## 计划卡片与操作

每个被搁置的计划都展示在一个卡片中，显示其 `#ID` 标签、标题、项目徽章、复杂度层级徽章以及验证指示器：

| 操作             | 控件           | 效果                                                                                                                                                                      |
| ---------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inspect Plan** | 点击卡片标题   | 在 [计划](03_Plans.md) 中打开计划工作区，以查看完整规范、元数据或历史修订版本。                                                                                           |
| **Thaw**         | 火焰图标按钮   | 乐观地将计划从 `Icebox` 状态转回 `Draft` 状态。计划立即离开待办箱并返回活跃的 [计划](03_Plans.md) 队列，随时可通过 [ExecutePlan](../02_Concepts/02_Promptwares.md) 执行。 |
| **Delete**       | 垃圾桶图标按钮 | 打开 `DeletePlanDialog` 永久删除计划文件夹、修订版本和数据库记录。                                                                                                        |
