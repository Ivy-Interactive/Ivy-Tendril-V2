# CLI

Tendril コマンドラインインターフェースは、ターミナルから直接、計画、プロジェクト、データベース、およびデーモンプロセスを管理するためのコマンドを提供します。

- [CLI の概要](00_Overview.md) — グローバルオプション、環境変数、および重要なトラブルシューティングコマンド。
- [plan](01_Plan.md) — 計画、ワークツリー、リビジョン、検証の作成、一覧表示、更新、および検証。
- [project](02_Project.md) — プロジェクト、リポジトリ、ビルド依存関係、レビューアクション、MCP サーバー、スキルの設定。
- [verification](03_Verification.md) — 再利用可能なグローバル検証チェックの定義と管理。
- [データベース](04_Database.md) — スキーマバージョン、マイグレーション、データベースリセット、整合性チェック、およびバキューム。
- [その他のコマンド](05_Other.md) — プロンプトウェアの実行、ジョブ追跡、チャットセッション、サービス登録、ユーティリティ。
- [config](06_Config.md) — `config.yaml` に保存されているトップレベル設定の読み取りと更新。
- [vault](07_Vault.md) — チームボルトの接続、共有リポジトリの検出、プロジェクトのインポートまたは公開。
