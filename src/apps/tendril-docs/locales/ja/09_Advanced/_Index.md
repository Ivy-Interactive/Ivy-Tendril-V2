# 高度な機能

Ivy Tendril の高度な設定、デーモン自動化、および CLI ツールについて説明します。

このセクションでは、コマンドラインインターフェース、計画やジョブをプログラムから実行するための REST デーモンエンドポイント、コーディングエージェントに公開される Model Context Protocol (MCP) サーバーについて解説します。

- [CLI リファレンス](01_CLI/_Index.md) — `tendril` コマンドラインインターフェース、サブコマンド、およびフラグの完全なリファレンス。
- [REST API](02_REST.md) — プログラムによる計画の実行、ジョブ管理、受信トレイへの送信、ヘルスチェック用のデーモンエンドポイント。
- [MCP サーバー](03_MCP.md) — Claude Code などの AI コーディングエージェントに公開されるツールとリソース。
