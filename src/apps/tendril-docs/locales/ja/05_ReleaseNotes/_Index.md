# リリースノート

Tendril の各リリースにおける変更点、新機能、パフォーマンスの向上、およびバグ修正を追跡します。

このセクションでは、Tendril デスクトップアプリケーション、CLI ユーティリティ、デーモンアーキテクチャ、およびエージェント実行環境に対する更新を時系列のログで提供します。

- [リリースノート](01_ReleaseNotes.md) — Tendril リリースの包括的なバージョン履歴と変更履歴。[Rust](https://www.rust-lang.org)、[Tauri v2](https://tauri.app)、[Vite+](https://viteplus.dev)、[React](https://react.dev)、[SQLite](https://www.sqlite.org) を採用した画期的な [Tendril v2](#) のアーキテクチャ刷新を取り上げています。

これらの機能が実際にどのように活用されているかを確認するには、[コンセプト](../02_Concepts/_Index.md)、[コーディングエージェント](../06_CodingAgents/_Index.md)、および [モデルプロバイダー](../08_ModelProviders/_Index.md) を参照してください。
