# リリースノート

## 2.0.0 (2026-09-21)

Tendril v2 は、Tendril プラットフォームの世代を超えたアーキテクチャの刷新です。デーモンとコア実行エンジンを [Rust](https://www.rust-lang.org) で再構築し、デスクトップアプリケーションに [Tauri v2](https://tauri.app) を採用、高性能な [Vite+](https://viteplus.dev) フロントエンドを導入し、ネイティブのマルチエージェントワークツリー並行処理、ライブターミナルインタラクション、拡張された [モデルプロバイダー](../08_ModelProviders/_Index.md) を追加しました。

### 主要なアーキテクチャの刷新

- **高性能 Rust デーモン (`tendril-server` および `tendril-core`)**: レガシーな .NET バックエンドを、[Tokio](https://tokio.rs) と [Axum](https://github.com/tokio-rs/axum) を採用した非同期 [Rust](https://www.rust-lang.org) デーモンに置き換えました。新しいデーモンは、ミリ秒未満のルーティングディスパッチ、ビジータイムアウト付きの堅牢な [SQLite](https://www.sqlite.org) コネクションプーリング、アトミックな設定ファイル書き込み、およびオーバーヘッドゼロのローカル IPC のための単一プロセスマスター選出プロトコルを提供します。
- **Tauri v2 デスクトップアプリケーション**: デスクトップシェルを [Tauri v2](https://tauri.app) に移行し、macOS、Linux、Windows 上でコンパクトかつメモリ効率の高いデスクトップ配布を実現しました。ネイティブシステム WebView、強化された IPC ブリッジ、ネイティブウィンドウ装飾、システムトレイ統合を活用し、従来のランタイムフレームワークへの依存を排除しました。
- **Vite+ React フロントエンド**: [Vite+](https://viteplus.dev) と [React 19](https://react.dev) を使用して、デスクトップユーザーインターフェースをゼロから再構築しました。`@ivy-interactive/components` とアトミックデザインのトークンおよびレンダラーコンポーネントを共有し、瞬時のホットリロード、統一テーマプリセット（Default、Dracula、Forest、Lovably）、およびレスポンシブなマルチブレークポイントレイアウトをサポートします。
- **並行ワークツリー実行**: 並行 [計画](../02_Concepts/01_Plans.md) 実行のために、マルチリポジトリ [git worktree](https://git-scm.com/docs/git-worktree) プロビジョニングを自動化しました。複数の [コーディングエージェント](../06_CodingAgents/_Index.md) が、git インデックスのロック、リポジトリの衝突、ブランチ切り替えの副作用を起こすことなく、分離されたブランチ上で異なる計画を同時に実行できます。アイドル状態または孤立したワークツリーを自動的に刈り取るバックグラウンドリーパーサービス（`worktreeReaperInterval` および `worktreeReaperGrace`）が含まれています。
- **ライブターミナルとインタラクティブチャット**: アプリケーションシェル内に直接 [Xterm.js](https://xtermjs.org) による組み込み [PTY](https://en.wikipedia.org/wiki/Pseudoterminal) ターミナルエミュレーションを導入しました。構造化チャットと生のターミナル操作（`chatMode: terminal` または `chatMode: chat`）を切り替えたり、stdin 経由で実行中のエージェントとやり取りしたり、ライブストリーミングされるツール実行を検査したり、セッション切り替えをまたいで保持されるキューイングプロンプトを維持したりできます。
- **拡張されたモデル統合とバンドルされたサイドカー**:
  - **バンドルされた OpenCode サイドカー**: [OpenCode](https://opencode.ai) CLI バイナリをデスクトップインストーラーに直接同梱（`binaries/opencode`）。個別での Node や CLI インストールを必要とせず、設定不要での [OpenCode エージェント](../06_CodingAgents/04_OpenCode.md) 実行と数百のオープンソースおよび商用モデルへの即時アクセスを可能にしました。
  - **Bring Your Own LLM (BYO LLM)**: [OpenAI](https://openai.com)、[Anthropic](https://www.anthropic.com)、および欧州のソブリンプロバイダー [Berget AI](../08_ModelProviders/01_Berget.md) (`https://api.berget.ai/v1`) 向けにファーストクラスのオンボーディングと設定カードを用意。ベース URL の自動正規化と OpenAI / Anthropic 両 SDK 変数への認証情報ディスパッチを備えています。
  - **Apple Foundation Model の統合**: macOS の `fm serve` を介した Apple オンデバイスモデルのネイティブサポート。クラウド API コストゼロで完全なオフラインプライバシーを保ちながらローカルで推論を実行します。
  - **動的モデルカタログの強化**: [models.dev](https://models.dev) からの動的なカタログ検出と、オフライン [SQLite](https://www.sqlite.org) キャッシュ、鮮度検出、および手動同期エンドポイント（`POST /api/models/refresh`）を統合しました。
  - **階層型モデルプロファイル**: サポートされているすべての [コーディングエージェント](../06_CodingAgents/_Index.md)（[Claude Code](../06_CodingAgents/01_ClaudeCode.md)、[Copilot](../06_CodingAgents/03_Copilot.md)、[Codex](../06_CodingAgents/02_Codex.md)、[Gemini](../06_CodingAgents/05_Gemini.md)、[Antigravity](https://antigravity.google)、[OpenCode](../06_CodingAgents/04_OpenCode.md)、[Cursor](https://cursor.com)、Apple）にわたる宣言的モデルプロファイル階層（`deep`、`balanced`、`quick`）を提供。設定可能な推論エフォートピッカー（`low`、`medium`、`high`、`max`）も含まれます。

### 機能

- **レビューアクションおよびエージェント向け組み込み PTY ターミナル**: リアルタイムのプロセスツリー追跡を備えた完全な ANSI 対応ターミナルタブ内で、レビューアクションとインタラクティブなエージェントセッションを実行できます。
- **マルチリポジトリ Git ワークツリー管理**: `Worktrees/<owner>/<repo>` 下に構造化された分離計画ワークスペース。ブランチ追跡、アップストリームベースブランチのフォーク検出、および未プッシュの安全なコミット保護を備えています。
- **一元化された Team Vault 同期**: 自動化された認証情報サニタイズ機能を備えた [Team Vault](../09_Advanced/01_CLI/07_Vault.md) を通じて、リモートの Git ベースの vault に対するプロジェクト設定、カスタム [MCP サーバー](../09_Advanced/03_MCP.md)、および [エージェントスキル](../06_CodingAgents/00_Skills.md) の接続、インポート、プッシュが可能です。
- **Cloudflare Quick Tunnels**: QR コード、[Argon2](https://en.wikipedia.org/wiki/Argon2) パスワードセッション保護、匿名レビュアーペルソナを使用して、安全な [Cloudflare](https://www.cloudflare.com) トンネル経由で読み取り専用の計画レビューとライブ検証ステータスを共有できます。
- **アプリ内設定エディタ**: ライブ競合検出、リロードフック、アシスタント主導のプロンプトアクションを備えた `config.yaml` 向けの構文色分け対応アプリ内エディタ（[設定のセットアップ](../03_Configuration/01_Setup.md) を参照）。

### 改善点

- **ミリ秒未満の CLI 起動**: `tendril` CLI を Rust（`src/crates/tendril-cli`）で書き直し、瞬時のコマンド起動とシームレスなデーモンプロキシを実現（[CLI の概要](../09_Advanced/01_CLI/00_Overview.md) を参照）。
- **トークンとコストの台帳**: 主要なプロバイダーモデル全体で調整されたリアルタイムのジョブ別トークン内訳シートとコスト追跡。カスタムエンドポイント用の自動フォールバック価格設定を備えています。
- **自動検証ソルバー**: ライブストリーミング出力と自動障害診断を備えた、プロジェクトチェック群（ビルド、テスト、フォーマット、lint）を実行する構造化検証ランナー（[検証チェック](../09_Advanced/01_CLI/03_Verification.md) を参照）。
- **統合 Markdown レンダラー**: 計画、ノート、ドキュメント全体で共通の Markdown レンダリングエンジン。GFM テーブル、シンタックスハイライト付きコードフェンス、[Mermaid](https://github.com/mermaid-js/mermaid) ダイアグラム、および [Review アプリ](../04_Apps/02_Review.md) での文字位置固定インライン差分コメントをサポートします。

## 1.2.0 (2026-09-01)

### 機能

- **再設計されたアプリシェル (Figma)** — 折りたたみ可能なナビゲーションセクション、持続的セッションタブ、統合プロジェクトステータスインジケーターを備えた、モダンなデスクトップシェルレイアウト (`#2173`)。
- **再設計された Tendril ダッシュボード** — リアルタイムステータスカウンター、アクティビティトレンド、アクティブジョブ追跡、Cloudflare Quick Tunnel QR コード表示を備えた新しい `TendrilDashboard` React ウィジェットを構築 (`#2201`)。
- **ドラフトから計画 (Plans) への統一** — コードベース全体で Drafts アプリ、サービス、モデルの名前を「Plans」に変更し、issue の取り込みから検証済み実行までの首尾一貫したライフサイクルを確立 (`#2258`)。
- **チャット添付ファイル用の HTTP マルチパートアップロード** — インライン Base64 送信をチャンク化された HTTP マルチパートアップロードに置き換え、大容量の画像やファイルに対する SignalR ペイロード制限を回避 (`#2255`, `#2224`)。
- **チャットでの持続的キューイングメッセージ** — キューに入ったメッセージはチャットセッションの切り替えをまたいで保持および表示され、エージェントがアクティブに実行されている間に開発者がプロンプトをキューに入れることが可能 (`#2253`)。
- **ページ内検索ショートカット (Ctrl+F / Cmd+F)** — レイアウトフローを乱すことなく、Markdown ビューおよび計画内でのページ内検索を追加 (`#2254`)。
- **レビューアクションのライブプレビュー** — プロジェクト設定内で直接レビューアクションをプレビューおよび実行できる機能を追加 (`#2225`)。
- **Lovably テーマプリセット** — Lovable デザインのトークンとカラースケールに基づいたモダンな UI テーマプリセットを追加 (`#2256`)。
- **等幅フォント CodeInput の拡大** — レビューアクションのコマンドおよび条件 (`#2247`)、MCP 環境変数 (`#2248`)、検証プロンプト (`#2249`)、プロジェクトメモリーの Markdown コンテンツ (`#2259`) にわたってシンタックス色分け対応の `CodeInput` を統合。
- **安全なチャットガードレール** — 探索的チャットセッション内での直接的な未検証コードベース編集を禁止し、変更に対する正式な計画作成を義務付け (`#2221`)。
- **Team Vault プロジェクトの競合時マージ** — ローカルプロジェクトと同名のリモート vault プロジェクトをインポートする際のインテリジェントなマージ解決を追加 (`#2219`)。

### 改善点

- **エージェントチャットおよび issue 生成プロンプトの強化** — 初回のエージェントチャットプロンプトおよび GitHub issue 作成に、完全なプロジェクトコンテキスト、リポジトリマッピング、添付ファイルメタデータを提供 (`#2226`)。
- **外観設定のテーマモードインジケーター** — 外観設定でアクティブなライト/ダークモードの状態を明確に表示 (`#2213`)。
- **テーマ対応 ContentInput ウィジェット** — カスタムテーマプリセット全体で入力バー、ボタン、ボーダーを動的に適応 (`#2241`)。
- **レビューアクショステーブルの簡素化** — 視認性向上のため、プロジェクト設定のレビューアクション設定テーブルを合理化 (`#2240`)。
- **ステージングコンテナのソースビルド** — 正確な PR プレビューブランチテストのために、ソースから直接ビルドするように Docker ステージングイメージを設定 (`#2229`)。
- **サイドバーのレイアウトと間隔の調整** — チャットサイドバーにおける完了チェックマークバッジの間隔と生成中セッションのレイアウトを微調整 (`#2220`, `#2223`)。
- **ネイティブのセッション削除ダイアログ** — セッション削除用の React モーダルポップアップをネイティブの `DeleteSessionDialog` ウィジェットに置き換え (`#2222`)。

### バグ修正

- **ジョブの可視性とキューの再水和** — アプリケーションの再起動後にジョブカードが表示されなくなる問題を修正し、アクティブなキューイングジョブの状態を正しく復元 (`#2243`)。
- **ゴーストブロックジョブのクリーンアップ** — 孤立または置き換えられたブロック中ジョブが SQLite ストレージや出力ビューに残留するのを防止 (`#2250`)。
- **Antigravity エージェントチャットのタイムアウト** — Antigravity エージェントセッションが時期尚早にタイムアウトせず、設定されたグローバルタイムアウトのデフォルトを尊重するように設定 (`#2218`)。
- **プロジェクト設定の検証編集ターゲット** — 編集時に検証ダイアログが誤った検証エントリを対象としてしまう問題を修正 (`#2252`)。
- **Markdown コードブロックのオーバーフロー** — 幅の広いコードスニペットが親計画コンテナから水平方向にはみ出すのを防止 (`#2214`)。
- **Dracula および Forest ダークテーマのコントラスト** — ダークテーマにおけるサイドバーアイテム、設定アイコン、タブのテキストとアイコンのホバー時視認性バグを解消 (`#2210`, `#2211`, `#2212`, `#2239`, `#2242`)。
- **重複サイドバーの排除** — アプリシェルの遷移中に発生していた冗長なサイドバーのレンダリングを排除 (`#2244`)。
- **解決済み issue における完了ドラフト状態** — 以前に解決された issue に対する計画生成時に完了できない状態になっていた問題を解消 (`#2217`)。
- **非推奨モデルのクリーンアップ** — 非推奨の Gemini 3.5 Flash モデル参照を削除し、Gemini 3.7 Flash に移行 (`#2215`)。
- **エフェメラルテスト成果物のクリーンアップ** — エンドツーエンドのテスト実行で一時ディレクトリとエージェントのスクラッチファイルがクリーンアップされることを保証 (`#2209`)。

## 1.1.36 (2026-08-28)

### 機能

- **ライブオンボーディングモデルテストと認証検証** — オンボーディング時に、ナビゲーションを許可する前にライブプロンプトリクエストを使用してエンドポイント認証情報とプロファイルモデル（`Deep`、`Balanced`、`Quick`）をアクティブにテストするようになり、無効なモデル名をブロックし、ネストされたプロキシエラーペイロードを明確なメッセージに展開します。
- **モデルプロファイル優先順位定数とプロバイダー列挙型** — 三項演算子の連続を宣言的な優先順位テーブル（`ModelProfilePriorities`）と列挙型（`ModelProviderKind`、`ModelProfileKind`）に置き換え、オンボーディングと設定全体で一貫したデフォルトおよび候補モデルの解決を実現。
- **オンデマンド Promptware デプロイフォールバック** — `Program.md` が存在しない場合に、埋め込みリソースからオンデマンドで不足している promptware を抽出する自動フォールバックデプロイを `PromptwareRunner` および `PromptwareRunCommand` に追加。

### 改善点

- **バンドルされた Ivy Agent バイナリの優先順位付け** — バンドルまたは Tendril 管理の `ivy-agent` バイナリ（`~/.tendril/bin`）の解決を強制し、管理外のシステム `PATH` 実行可能ファイルがエージェントの実行に干渉するのを防止。
- **設定におけるカスタムモデル入力の持続性** — `CodingAgentSetupView` で Enter キーまたは再レンダリング時にカスタムモデル名入力が元に戻ってしまう問題を修正。
- **ゴミ箱機能の削除** — 廃止されたゴミ箱アプリとコマンド群を削除し、ゴミ箱マーカーを `CreatePlan` におけるクリーンな重複拒否処理に置き換え。

## 1.1.35 (2026-08-28)

### 機能

- **共有モードトンネルと外部共有 `[ベータ]`** — ベータフラグ（設定の `beta: true` または `TENDRIL_BETA`）のもとで、自動共有 URL 生成とコピー操作により、Cloudflare トンネル経由で計画とドラフトリンクを安全に外部共有。
- **共有モードのセッション保護** — 設定の統一された「セキュリティとトンネリング」セクションの下に、Argon2 ハッシュによるパスワードセッション保護を追加。
- **匿名レビュアーペルソナ** — 共有された計画をレビューする外部コラボレーター向けに、イニシャル付きアバターを持つわかりやすい匿名ペルソナを生成。
- **ドラフトと計画の差分インラインコメント** — 専用の「変更をリクエスト」アクションとバッジ数を備えた、レビューモードでの差分チャンクに対するリアルタイムインラインレビューコメント（`DraftDiffCommentService`）を追加。
- **ドラフトテキスト選択アノテーション** — `DraftMarkdown`（`DraftAnnotationService`）に、文字オフセットに固定されたテキスト選択ハイライトとポップオーバーを追加。
- **チーム設定 Vault `[ベータ]`** — Git リポジトリをバックエンドとする一元的なチーム設定同期（`VaultService`、ベータフラグ下で利用可能）を導入。自動化されたシークレットサニタイズ（`VaultSecretSanitizer`）により、チームがプロジェクト設定をリモート vault に作成、接続、インポート、プッシュ可能に。

### 改善点

- **ジョブの出所とプロファイルの記録** — ジョブごとの実行プロファイルと構造化されたコストシートの出所をファクトとして記録。
- **ベータ機能の分離** — UI およびコマンドレイヤーの両方で、共有ボタン、トンネルコントロール、vault 設定がベータフラグの背後にクリーンに分離されていることを保証。

### バグ修正

- **Windows デスクトップパッケージング** — Windows x64 および arm64 ビルドでバンドルされた `ivy-agent.exe` に対し junk-path zip 展開を使用することで、パッケージングの失敗を修正。

## 1.1.34 (2026-08-25)

### 機能

- **レビューアクション用の組み込み PTY ターミナル** — レビューアクションが、外部ターミナルウィンドウを起動する代わりに、Xterm（`ReviewActionApp`）を搭載したレスポンシブな組み込みターミナルタブで実行されるように変更。
- **バンドルされた Ivy Agent CLI** — スタンドアロンの `ivy-agent` 実行可能ファイルを Tendril アプリケーションインストーラーに直接同梱し、手動インストールの必要性を排除。
- **Bring Your Own LLM (BYO LLM) とモデルカタログ** — オンボーディングおよび設定全体で、BYO LLM 設定と Ivy Proxy 向けのプロバイダーカタログとモデルセレクターを追加。Gemini 3.7 Flash、Claude モデル、OpenAI 推論モデルをサポート。
- **モデル推論エフォートの選択** — コーディングエージェントプロファイル設定において、サポートされている推論モデル向けのエフォートレベルピッカー（low、medium、high）を導入。
