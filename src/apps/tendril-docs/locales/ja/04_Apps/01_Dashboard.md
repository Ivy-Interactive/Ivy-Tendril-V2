# ダッシュボード

ダッシュボードは Tendril の主要な運用概要画面であり、すべてのプロジェクトにわたる開発パイプライン、エージェント支出、提供スピード、およびアクティブなジョブをリアルタイムで可視化します。

## ヘッダーとパイプラインの概要

ダッシュボードの上部には、現在の日付、時間帯に応じた挨拶、および **プロセスビューアー (Process Viewer)**（`TendrilProcessViewer`）が表示されます：

- **Drafts（ドラフト）** — 推敲または実行を待っている `Draft` 状態の現在の計画の総数。
- **In-Flight Jobs（実行中ジョブ）** — プロンプトウェアフェーズ（**Creating**、**Updating**、**Executing**、**Retrying**、および **Creating PR**）ごとに分類されたアクティブなエージェントジョブのリアルタイムカウント。
- **Review（レビュー）** — 開発者のトリアージと承認を待っている実行完了済みの計画。
- **Completed & Failed（完了および失敗）** — 終了したジョブの累積カウント。

プロセスビューアー内のステージをクリックすると、そのビュー（[計画](03_Plans.md)、[ジョブ](04_Jobs.md)、または [レビュー](02_Review.md)）に直接移動します。**+ New Plan** アクションもビューアーから直接アクセスできます。

## 主要業績評価指標 (KPI)

4 つのプライマリ KPI カードが開発速度とコスト効率を要約します：

| 指標                     | 意味                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------- |
| **Features Shipped**     | すべてのプロジェクトで提供された、完了した計画およびマージされたプルリクエストの総数。 |
| **Avg cost per Feature** | 完了した機能を提供するのに必要な平均ドル支出。                                         |
| **Forecast This Month**  | 直近 30 日間の消費率から算出された月間予測支出。                                       |
| **Avg Cost/Plan**        | 入力、出力、キャッシュトークンを考慮した、実行されたすべての計画の平均コスト。         |

### ドリルダウン内訳ブレード

KPI カードをクリックすると、詳細な **内訳ブレード (Breakdown Blade)**（`BladeContainer`）がスライド表示されます：

- **プロジェクトおよびエージェントの内訳** — どのプロジェクトまたはコーディングエージェントがトークン消費量とコストの大部分を占めているかを確認できます。
- **計画内訳テーブル** — 計画タイトル、実行時間、トークン数（入力、出力、キャッシュ読み取り、推論）、および合計コストを一覧表示する詳細な計画ごとの監査テーブル。
- **直接ナビゲーション** — 内訳ブレード内の計画をクリックして、その完全な仕様を開きます。

## 28 日間の日次トレンド

**日次トレンド (Daily Trend)** カードは、28 日間のウィンドウにおける日々の実行アクティビティとトークン支出をプロットします：

- **棒グラフ** — 日ごとのコストとアクティビティの合計。
- **7 日間移動平均** — 日々のばらつきを平滑化し、提供傾向を強調するためにチャート上に重ねて表示された移動平均曲線。

## プルリクエスト

**プルリクエスト (Pull Requests)** カードは以下を提供します：

- **週次 PR 頻度** — 6 週間のローリングウィンドウでマージされたプルリクエストをプロットする棒グラフ。
- **最近のマージ** — プロジェクトバッジと [プルリクエスト](06_PullRequests.md) で開くリンクを備えた、最近マージされた [GitHub](https://github.com) プルリクエストのクイックリスト。

## アクティブなジョブ

**アクティブなジョブ (Active Jobs)** カードには、現在実行中のエージェントジョブがリアルタイムで最大 8 件表示されます：

- **ライブステータス** — ステータスバッジ（`Running`、`Pending`、または `Blocked`）を表示します。
- **対象の計画とプロンプトウェア** — 計画タイトルまたは特定の [プロンプトウェア](../02_Concepts/02_Promptwares.md) タイプ（`CreatePlan`、`ExecutePlan`、`UpdatePlan` など）を特定します。
- **直接確認** — ジョブをクリックすると、[ジョブ](04_Jobs.md) アプリでそのライブ出力ターミナルが開きます。

## コストとトークンの会計処理

すべてのプロンプトウェアの実行は、`$TENDRIL_HOME/plans/<planId>/costs.csv` にある計画の永続的な `costs.csv` ファイルに行を追記します。

Tendril はこれらの CSV レコードを [SQLite](https://www.sqlite.org) データベースに照合し、ライブの [models.dev](https://models.dev) 価格仕様（プロンプトトークン、完了トークン、プロンプトキャッシュの読み取り/書き込み、推論トークンなど）を使用してコストを計算します。すべてのグラフは、[プロジェクト設定](../03_Configuration/02_Projects.md) で構成されたプロジェクトカラーとともに、これらの照合された数値を反映します。
