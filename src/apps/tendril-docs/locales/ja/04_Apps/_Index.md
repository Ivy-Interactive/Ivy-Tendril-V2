# アプリ

Tendril は、ソフトウェアの計画と実行の [計画ライフサイクル](../02_Concepts/03_Lifecycle.md) の個別のフェーズに合わせて設計された、特化型のデスクトップアプリとビューを提供します：

- [ダッシュボード](01_Dashboard.md) — 計画パイプラインのフロー、ドリルダウン内訳ブレード付き KPI 指標、28 日間の日次トレンド、およびアクティブな [ジョブ](04_Jobs.md) モニターを備えた運用概要。
- [レビュー](02_Review.md) — 承認待ちの完了した計画、検証ログ、インライン変更リクエスト、プロジェクトレビューアクション、および [GitHub](https://github.com) プルリクエスト作成のための決定キュー。
- [計画](03_Plans.md) — 複数リビジョン間の差分、埋め込みチャット、検証ゲート、および [プロンプトウェア](../02_Concepts/02_Promptwares.md) 実行コントロールを備えた計画のドラフト作成・推敲ワークスペース。
- [ジョブ](04_Jobs.md) — ライブターミナル出力ストリーミング、トークン/コスト内訳、デバッグシート、およびプロセス管理を備えた実行モニターおよび監査ログ。
- [アイスボックス](05_Icebox.md) — 全文検索、プロジェクトおよびレベルによるフィルタリング、アクティブな [計画](03_Plans.md) へのワンクリック解凍機能を備えた、保留中および延期された計画のためのバックログステージング領域。
- [プルリクエスト](06_PullRequests.md) — [GitHub CLI](https://cli.github.com) を介したバックグラウンドステータス同期、費用指標、およびフォローアップ計画生成を備えた、[GitHub](https://github.com) プルリクエストのクロスプロジェクト追跡。
- [レコメンデーション](07_Recommendations.md) — ワンクリックでの承認と [GitHub](https://github.com) issue 作成機能を備えた、コードベースの改善と不足しているテストカバレッジに関する自動提案。

これらのアプリに連携するプロジェクトやエージェントの構成手順については、[セットアップと設定](../03_Configuration/01_Setup.md) および [プロジェクト設定](../03_Configuration/02_Projects.md) を参照してください。
