# プルリクエスト

プルリクエストアプリは、承認された Tendril 計画から作成されたすべての [GitHub](https://github.com) プルリクエストのクロスプロジェクト追跡を提供します。各デリバリーに関連するトークン支出とコストとともに、どの PR がオープン、マージ、またはクローズされているかを監視するための単一のダッシュボードを提供します。

## PR のライフサイクルとワークフロー

1. **承認** — 計画の実行が終了し [レビュー](02_Review.md) で承認されると、**Create Pull Request** をクリックして `CreatePr` プロンプトウェアを起動します（[プロンプトウェア](../02_Concepts/02_Promptwares.md) を参照）。
2. **作成** — Tendril は [GitHub CLI](https://cli.github.com)（`gh`）を使用して、分離された [Git](https://git-scm.com) ワークツリーブランチをプッシュし、AI が生成した要約とともに [GitHub](https://github.com) でプルリクエストを開きます（[GitHub 統合](../07_Integrations/01_Github.md) を参照）。
3. **追跡** — プルリクエストは計画にリンクされ、マージまたはクローズされるまでこのビューで追跡されます。

## プルリクエストテーブル

テーブルには、プロジェクト全体で記録されたすべてのプルリクエストが一覧表示されます：

| カラム         | 説明                                                               | インタラクション                                                                              |
| -------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Plan**       | 計画の `#ID` とタイトル。                                          | クリックして完全な計画仕様を表示するスライドオーバープレビューシートを開く。                  |
| **Project**    | プロジェクトバッジ。                                               | [プロジェクト設定](../03_Configuration/02_Projects.md) で定義されたプロジェクトカラーを表示。 |
| **Status**     | ステータスバッジ（`Open`、`Merged`、`Closed`、または `Unknown`）。 | ホバーツールチップに最後の GitHub チェックのタイムスタンプを表示。                            |
| **PR**         | GitHub プルリクエスト番号（例：`#84`）。                           | クリックしてデフォルトブラウザで [GitHub](https://github.com) 上のプルリクエストを開く。      |
| **Tokens**     | 計画によって消費された累積トークン数。                             | コンパクトなトークンカウント表示（例：`450K`、`1.2M`）。                                      |
| **Cost**       | この計画のすべてのジョブの合計 USD コスト。                        | フォーマットされた通貨支出。                                                                  |
| **Repository** | GitHub リポジトリターゲット（`owner/repo`）。                      | 完全なターゲットリポジトリパス。                                                              |
| **Branch**     | Git ブランチ名。                                                   | リポジトリ内のソースブランチ。                                                                |

## フィルタリングと同期

- **ステータスフィルター** — テーブルの上のステータスバッジセレクターを使用して、`Open`、`Merged`、`Closed`、または `Unknown` でフィルター処理します。
- **検索** — 計画 ID、タイトル、プロジェクト名、リポジトリ、またはブランチ名にわたってリアルタイムで行をフィルタリングします。
- **GitHub との再同期** — **Resync** ボタンをクリックして、構成されたリポジトリ全体で同期パス（`gh pr list`）を実行します。Tendril は、到達不能、未認証、またはレート制限されたリポジトリを報告します。

> [!NOTE]
> マージされたプルリクエストは最終状態とみなされ、定期的な同期パス中に再チェックされることはありません。

## 行アクション

各プルリクエスト行には 4 つのクイックアクションが用意されています：

- **View Plan** — [計画](03_Plans.md) アプリの計画詳細ワークスペースに移動します。
- **Follow Up** — リポジトリ、プロジェクト、ブランチの参照が事前に入力された新規計画ダイアログを開き、[計画](03_Plans.md) でフォローアップタスク、バグ修正、または機能改善を簡単に作成できるようにします。
- **Open PR** — Web ブラウザで [GitHub](https://github.com) 上のプルリクエストを開きます。
- **Resync** — その特定のリポジトリのステータスを GitHub から更新します。
