# アイスボックス

アイスボックスは、延期された計画、優先度の低い計画、または将来のエンジニアリング計画のための Tendril 専用のバックログおよび保管スペースです。計画を保留（シェルブ）しておくことで、調査、議論、ドラフトされた仕様を失うことなく、アクティブな [計画](03_Plans.md) のドラフトキューを現在のスプリントの優先事項に集中させることができます（[計画ライフサイクル](../02_Concepts/03_Lifecycle.md) を参照）。

## 計画の保留 (Shelving Plans)

計画は、`Draft` または `Blocked` 状態であればいつでも保留できます：

- [計画](03_Plans.md) アプリのアクションメニューから **Shelve to Icebox** を選択します。
- Tendril は計画のステータスを `Icebox` に更新します。
- `$TENDRIL_HOME/plans/<planId>/` の下にある計画ディレクトリ、バージョン管理されたリビジョン、およびコスト記録は、ディスク上に完全に保持されます（[CLI 計画管理](../09_Advanced/01_CLI/01_Plan.md) を参照）。

## 閲覧とフィルタリング

アイスボックスアプリは、バックログ全体に対する焦点を絞った検索とフィルタリングを提供します：

- **検索バー** — タイトルのキーワードまたは数値の計画 `#ID` で計画をフィルタリングします。
- **プロジェクトフィルター** — [プロジェクト設定](../03_Configuration/02_Projects.md) で構成された特定のプロジェクトに保留中の計画を絞り込みます。
- **レベルフィルター** — 複雑度階層（[セットアップと設定](../03_Configuration/01_Setup.md#in-app-settings) で構成された L1、L2、L3 など）で計画をフィルタリングします。

## 計画カードとアクション

保留された各計画は、その `#ID` タグ、タイトル、プロジェクトバッジ、複雑度レベルバッジ、および検証インジケーターを示すカードに表示されます：

| アクション       | コントロール             | 効果                                                                                                                                                                                                           |
| ---------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inspect Plan** | カードタイトルをクリック | [計画](03_Plans.md) で計画ワークスペースを開き、完全な仕様、メタデータ、または過去のリビジョンを確認します。                                                                                                   |
| **Thaw**         | 炎のアイコンボタン       | 計画を `Icebox` から `Draft` へと楽観的に遷移させます。計画は直ちにアイスボックスを離れ、[ExecutePlan](../02_Concepts/02_Promptwares.md) を介して実行可能なアクティブな [計画](03_Plans.md) キューに戻ります。 |
| **Delete**       | ゴミ箱アイコンボタン     | `DeletePlanDialog` を開き、計画フォルダー、リビジョン、およびデータベースレコードを完全に削除します。                                                                                                          |
