# 計画

計画アプリは、コード変更を実行する前にエンジニアリング作業を形成、推敲、および準備するための Tendril のワークスペースです。最初に計画を練ることで、エージェントの実行ランを開始する前に、要件、アーキテクチャ、および検証手順が明確になります。

## ドラフトの管理

- **計画の作成** — `Ctrl+Alt+N`（macOS では `Cmd+Option+N`）を押すか、シェルヘッダーの **+ New Plan** をクリックして作成ダイアログを開きます。
- **ドラフトキュー** — サイドバーには、`Draft` または `Blocked` ステータスのすべての計画が一覧表示されます。現在実行ジョブで実行中の計画は、同時編集を避けるためにドラフトキューから安全に除外されます。
- **バッジ** — 各ドラフトには、その `#ID` タグ、タイトル、プロジェクトバッジ、およびプロジェクトの構成されたレベルパレットでスタイル設定された複雑度レベルバッジ（例：L1、L2、L3）が表示されます。
- **プロセス壁紙** — キューが空の場合、Tendril は計画、[レビュー](02_Review.md)、および [ジョブ](04_Jobs.md) へのナビゲーションを備えたインタラクティブなプロセスライフサイクルの壁紙を表示します。

## 計画ワークスペース (`PlanWorkspace`)

計画を選択すると、高機能なワークスペースインターフェースが開きます：

### タブ

- **Plan（計画）** — リアルタイムのタスクチェックリスト、問題の説明、提案されたアプローチ、および検証基準を含む、最新の計画仕様リビジョンを [Markdown](https://www.markdownguide.org) で表示します。
- **Details（詳細）** — 計画のメタデータ、割り当てられたプロジェクトコンテキスト（[プロジェクト設定](../03_Configuration/02_Projects.md) より）、作成/更新日時、およびリビジョン履歴。
- **Diff View（差分ビュー）** — 計画に複数のリビジョンがある場合（`revisionCount > 1`）に表示され、リビジョン間の並列または統合された差分比較を提供します。
- **Recommendations（レコメンデーション）** — この計画に対して生成されたプロアクティブな [レコメンデーション](07_Recommendations.md) を、インラインの承認 (Accept) および却下 (Decline) のトリアージコントロールとともに一覧表示します。
- **Git** — 実行アーティファクトが存在する場合に表示されます。アクティブな [Git](https://git-scm.com) ワークツリー、記録されたコミット、PR 参照（[プルリクエスト](06_PullRequests.md) を参照）を追跡し、マージされていないコミットが失われるリスクがある場合に警告を発し、ワークツリーをリモートと同期するボタンを提供します。

### パネルとチャット

- **検証パネル (Verifications Panel)** — 右上のドロップダウンからアクセスでき、構成された [検証](../03_Configuration/01_Setup.md#verifications) ゲート（`Build`、`Test`、`Lint` など）をリアルタイムの合否ステータスと出力ログとともに表示します。
- **計画チャット (Plan Chat)** — コード変更を開始する前に、ブレーンストーミングを行ったり、アプローチを洗練したり、計画についてエージェントに質問したりするための埋め込み型インタラクティブチャットパネル（`PlanChatPanel`）。

## プロンプトウェアアクション

これらのワークフローがどのように実行されるかの背景については、[プロンプトウェア](../02_Concepts/02_Promptwares.md) を参照してください：

| アクション           | 目的                                                                                                                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ExecutePlan**      | 最新の計画リビジョンをロックし、分離された [Git](https://git-scm.com) ワークツリーブランチを作成し、変更を実装するために [コーディングエージェント](../06_CodingAgents/_Index.md) を起動します。 |
| **ExpandPlan**       | 簡潔な概要を、詳細な手順、対象ファイル、テスト計画を含む構造化された計画へと具体化するようエージェントに促します。                                                                               |
| **SplitPlan**        | 大規模または複雑な計画を、個別に実行可能なより小さく焦点を絞ったサブ計画に分割します。                                                                                                           |
| **Shelve to Icebox** | すべてのコンテキストを保持したままアクティブなキューを整理するために、計画を [アイスボックス](05_Icebox.md) に移動します。                                                                       |
| **Delete Plan**      | 計画フォルダーとレコードを完全に削除するための確認を求めます。                                                                                                                                   |

## ディスク上のファイルとリアルタイム同期

すべての計画は、`$TENDRIL_HOME/plans/<planId>/` 下のディレクトリによって管理されます：

- `plan.yaml` — [YAML](https://yaml.org) 形式の計画メタデータ、状態、プロジェクト関連付け、および検証レコード。[CLI 計画管理](../09_Advanced/01_CLI/01_Plan.md) を参照。
- `revisions/` — 仕様の各イテレーションを表すバージョン管理された Markdown ファイル（`001.md`、`002.md` など）。
- `costs.csv` — 追記専用のトークンおよびコスト元帳。

Tendril はファイルシステムウォッチャーを使用して外部テキストエディタや IDE で行われた編集を検出し、手動で更新することなく UI を即座に更新します。
