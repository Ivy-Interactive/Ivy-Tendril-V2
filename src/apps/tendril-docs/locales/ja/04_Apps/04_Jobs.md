# ジョブ

ジョブアプリは、Tendril のリアルタイム実行モニターおよび履歴監査ログです。すべての [プロンプトウェア](../02_Concepts/02_Promptwares.md) 呼び出し（`CreatePlan`、`ExecutePlan`、`UpdatePlan`、`CreatePr`、`SplitPlan` など）は、ここで追跡される非同期ジョブとして実行されます。

## 概要とステータス進捗

ジョブビューの上部にある **積み上げプログレスバー (Stacked Progress Bar)**（`StackedProgress`）は、ジョブ状態のリアルタイム分布を表示します：

- **Running**（青）— アクティブに実行中のエージェントプロセス。
- **Completed**（緑）— 正常に終了した実行。
- **Failed**（赤）— エラーで終了したか検証に合格しなかった実行。
- **Blocked**（黄）— 依存関係、並行実行制限、または操作者の確認を待機しているジョブ。
- **Pending**（グレー）— 利用可能なエージェントスロットを待機しているキュー内のジョブ。

ヘッダーの一括実行コントロールを使用すると、必要に応じてオペレーターは **Stop All Queued** または **Stop All** でジョブを停止でき、**Clear** ドロップダウンメニュー（`Clear Completed`、`Clear Failed`、または `Clear All`）から履歴行を一括消去できます。

## ジョブテーブル

テーブルは、デーモン側で評価されるサーバーサイドの並べ替えとフィルタリングを備えた無限スクロールを使用します：

| カラム      | 説明                                                         | インタラクション                                                                                 |
| ----------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| **Id**      | 数値のジョブ識別子（例：`00042`）。                          | ヘッダーをクリックして新しい順/古い順に並べ替え。                                                |
| **Plan Id** | 対象の計画識別子。                                           | クリックして [計画](03_Plans.md) の計画へ直接移動。                                              |
| **Status**  | 現在のジョブステータスバッジ。                               | 状態ごとに色分け。                                                                               |
| **Type**    | プロンプトウェア識別子（例：`ExecutePlan`）。                | プロンプトウェアごとに並べ替え可能。                                                             |
| **Project** | プロジェクトバッジ。                                         | [プロジェクト設定](../03_Configuration/02_Projects.md) のプロジェクトカラーで装飾。              |
| **Output**  | エージェントの実行状態（`running`、`done`、`idle`）。        | **クリックしてストリーミングターミナル出力を備えたライブ出力シート**（`JobSessionView`）を開く。 |
| **Tokens**  | 総トークン消費量。                                           | **クリックしてコストとトークンのシート**（`JobCostSheet`）を開く。                               |
| **Cost**    | USD で計算された実行コスト。                                 | **クリックしてコストとトークンのシート** を開く。                                                |
| **Timer**   | リアルタイムの経過時間タイマーまたは記録された実行所要時間。 | リアルタイムの所要時間を表示。                                                                   |
| **Date**    | ジョブが開始されたタイムスタンプ。                           | 時系列順に並べ替え。                                                                             |

## シートとスライドオーバー

セルまたは行のアクションをクリックすると、現在の位置を見失うことなく、テーブルの上に直接スライドオーバーシートが開きます：

### ライブ出力シート (`JobSessionView`)

**Output** セルをクリックすると、リアルタイムにストリーミングされるエージェントビューアーが開きます。一般的なスピナーだけでなく、エージェントからのリアルタイムな `stdout`/`stderr` ターミナル出力（ビルドログ、テスト出力、ツール呼び出し、エージェントの推論プロセス）を確認できます。

### コストとトークンシート (`JobCostSheet`)

**Tokens** または **Cost** セルをクリックすると、詳細な会計内訳が表示されます：

- **入力トークン (Input Tokens)** — モデルに送信されたプロンプトおよびコンテキストトークン。
- **出力トークン (Output Tokens)** — モデルによって生成されたトークン。
- **キャッシュ読み取りトークン (Cache Read Tokens)** — プロンプトキャッシュから提供されたトークン（コストとレイテンシを節約）。
- **キャッシュ書き込みトークン (Cache Write Tokens)** — プロバイダーのプロンプトキャッシュに書き込まれたトークン。
- **推論トークン (Reasoning Tokens)** — 内部推論モデル（OpenAI o1/o3 や Anthropic extended thinking など）で消費されたトークン。
- **コスト計算 (Cost Calculation)** — [models.dev](https://models.dev) 価格仕様に対して照合された通貨コスト。

### 完全なプロンプトシート

**Prompt** テキストをクリックすると、完全な構文ハイライト付きでエージェントに送信された切り捨てのない完全なプロンプトが開きます。

## 行アクションメニュー

各ジョブ行にはアクションメニュー（`...`）が用意されています：

| アクション      | 利用可能対象       | 効果                                                                                                                                                                  |
| --------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stop**        | アクティブなジョブ | 実行中のエージェントプロセスを直ちに終了します。[Git](https://git-scm.com) ワークツリーは保持されるため、途中経過の再開や検査が可能です。                             |
| **Force Start** | Blocked のジョブ   | 並行実行制限や依存関係ロックをバイパスして、直ちにジョブを起動します。                                                                                                |
| **Debug**       | すべてのジョブ     | **ジョブデバッグシート**（`JobDebugSheet`）を開き、Job Log、Job Prompt、Raw Output Log、および Eventwire Log へのタブアクセスと「Open in Editor」ボタンを提供します。 |
| **Delete**      | Completed / Failed | 確認の上、履歴からジョブレコードを完全に削除します。                                                                                                                  |
