# インテグレーション

Tendril を外部ツールやサービスと接続して開発ワークフローを効率化し、[計画の実行](../02_Concepts/01_Plans.md)を自動化します。

- [GitHub](01_Github.md) — [GitHub](https://github.com) との Issue のインポート、Pull Request の自動作成、PR ステータスの同期。
- [Jam.dev](02_JamDev.md) — [Jam.dev](https://jam.dev) 受信トレイ API Webhook を介したバグレポートからの自動計画作成。
- [OpenClaw](03_OpenClaw.md) — Tendril Inbox ドロップフォルダーを介した、OpenClaw などの外部ツールからのファイルベースの計画取り込み。
