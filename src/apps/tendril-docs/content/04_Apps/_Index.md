# Apps

Tendril provides specialized desktop apps and views designed for distinct phases of the software planning and execution lifecycle:

- [Dashboard](01_Dashboard.md) — Landing view displaying plan counts, burn rate, token spend, and recent activity across projects.
- [Review](02_Review.md) — Queue of completed or failed plans awaiting developer approval, diff inspection, and verification logs.
- [Plans](03_Plans.md) — Active drafts and blocked plans where work is shaped and refined before execution.
- [Jobs](04_Jobs.md) — Real-time monitor for active and past promptware runs with live terminal logs and execution controls.
- [Icebox](05_Icebox.md) — Staging area for low-priority or deferred plans to keep active draft queues focused.
- [Pull Requests](06_PullRequests.md) — Track, inspect, and merge GitHub pull requests generated directly from approved plans.
- [Recommendations](07_Recommendations.md) — Automated suggestions for codebase improvements, refactoring, and missing test coverage.
