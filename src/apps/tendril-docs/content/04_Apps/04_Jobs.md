# Jobs

The Jobs app is Tendril's real-time execution monitor and historical audit log. Every [Promptware](../02_Concepts/02_Promptwares.md) invocation (`CreatePlan`, `ExecutePlan`, `UpdatePlan`, `CreatePr`, `SplitPlan`, etc.) runs as an asynchronous job tracked here.

## Overview & Status Progress

At the top of the Jobs view, a **Stacked Progress Bar** (`StackedProgress`) displays the real-time distribution of job states:

- **Running** (blue) — Actively running agent processes.
- **Completed** (green) — Successfully finished executions.
- **Failed** (red) — Runs that exited with errors or failed verifications.
- **Blocked** (amber) — Jobs waiting on dependencies, concurrency limits, or operator confirmation.
- **Pending** (muted) — Queued jobs waiting for available agent slots.

Bulk execution controls in the header allow operators to **Stop All Queued** or **Stop All** jobs when needed, or batch-clear historical rows via the **Clear** dropdown menu (`Clear Completed`, `Clear Failed`, or `Clear All`).

## The Jobs Table

The table uses infinite scrolling with server-side sorting and filtering evaluated daemon-side:

| Column      | Description                                        | Interaction                                                                                |
| ----------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Id**      | Numeric job identifier (e.g. `00042`).             | Click header to sort newest/oldest.                                                        |
| **Plan Id** | The target plan identifier.                        | Click to navigate directly to the plan in [Plans](03_Plans.md).                            |
| **Status**  | Current job status badge.                          | Color-coded by state.                                                                      |
| **Type**    | Promptware identifier (e.g. `ExecutePlan`).        | Sortable by promptware.                                                                    |
| **Project** | Project badge.                                     | Styled with project color from [Project Setup](../03_Configuration/02_Projects.md).        |
| **Output**  | Agent execution state (`running`, `done`, `idle`). | **Click to open the Live Output Sheet** (`JobSessionView`) with streaming terminal output. |
| **Tokens**  | Total token consumption count.                     | **Click to open the Cost & Tokens Sheet** (`JobCostSheet`).                                |
| **Cost**    | Calculated execution cost in USD.                  | **Click to open the Cost & Tokens Sheet**.                                                 |
| **Timer**   | Live elapsed timer or recorded run duration.       | Displays real-time duration.                                                               |
| **Date**    | Timestamp when the job was launched.               | Chronological sorting.                                                                     |

## Sheets & Slide-Overs

Clicking cells or row actions opens focused slide-over sheets directly over the table without losing your place:

### Live Output Sheet (`JobSessionView`)

Clicking the **Output** cell opens the live streaming agent viewer. You see the real-time `stdout`/`stderr` terminal output from the agent (build logs, test output, tool invocations, and agent reasoning), not just a generic spinner.

### Cost & Tokens Sheet (`JobCostSheet`)

Clicking the **Tokens** or **Cost** cell reveals a detailed accounting breakdown:

- **Input Tokens** — Prompt and context tokens sent to the model.
- **Output Tokens** — Tokens generated by the model.
- **Cache Read Tokens** — Tokens served from prompt cache (saving cost and latency).
- **Cache Write Tokens** — Tokens written into the provider prompt cache.
- **Reasoning Tokens** — Tokens spent on internal reasoning models (e.g. OpenAI o1/o3 or Anthropic extended thinking).
- **Cost Calculation** — Currency cost reconciled against [models.dev](https://models.dev) pricing specs.

### Full Prompt Sheet

Clicking the **Prompt** text opens the complete, untruncated prompt sent to the agent with full syntax highlighting.

## Row Actions Menu

Each job row provides an actions menu (`...`):

| Action          | Availability       | Effect                                                                                                                                                                |
| --------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stop**        | Active jobs        | Terminates the running agent process immediately. The [Git](https://git-scm.com) worktree is preserved so you can resume or inspect partial progress.                 |
| **Force Start** | Blocked jobs       | Bypasses concurrency caps or dependency locks to launch the job immediately.                                                                                          |
| **Debug**       | All jobs           | Opens the **Job Debug Sheet** (`JobDebugSheet`) providing tabbed access to the Job Log, Job Prompt, Raw Output Log, and Eventwire Log, with "Open in Editor" buttons. |
| **Delete**      | Completed / Failed | Permanently deletes the job record from history with confirmation.                                                                                                    |
