# Integrations

Connect Tendril with external tools and services to streamline your development workflow.

- [GitHub](01_Github.md) — issue importing, automatic pull request creation, and PR status synchronization.
- [Jam.dev](02_JamDev.md) — automated plan creation from bug reports via the inbox API webhook.
- [OpenClaw](03_OpenClaw.md) — file-based plan ingestion via the Tendril Inbox drop folder.
