# Getting Started

Six pages, in reading order. The first two get Tendril running; the next two get it running
*unattended* against your own repository, which is where the value is.

- [Introduction](01_Introduction.md) — what Tendril is, how it is put together, and why it works the
  way it does.
- [Installation](02_Installation.md) — prerequisites, building from source, and where configuration
  lives.
- [Onboarding a Codebase](03_Onboarding.md) — the machine and repository checklist to work through
  before your first real plan.
- [Tutorial](04_Tutorial.md) — a full loop: register a project, create a plan, execute it, review the
  diff, open a pull request.
- [Getting Help](05_GettingHelp.md) — Discord, GitHub issues, and what to attach to a bug report.
- [Troubleshooting](06_Troubleshooting.md) — symptoms and fixes, by area.

When you are through these, [Concepts](../02_Concepts/_Index.md) explains the model underneath:
plans, promptwares and the job lifecycle.
