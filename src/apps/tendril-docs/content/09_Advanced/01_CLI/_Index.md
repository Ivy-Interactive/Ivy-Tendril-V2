# CLI

The Tendril command line interface provides commands for managing plans, projects, databases, and daemon processes directly from your terminal.

- [CLI Overview](00_Overview.md) — global options, environment variables, and essential troubleshooting commands.
- [plan](01_Plan.md) — create, list, update, and validate plans, worktrees, revisions, and verifications.
- [project](02_Project.md) — configure projects, repositories, build dependencies, and review actions.
- [verification](03_Verification.md) — define and manage reusable global verification checks.
- [Database](04_Database.md) — schema versions, migrations, and database resets.
- [Other Commands](05_Other.md) — promptware execution, job inspection, master claim recovery, and agent instructions.
- [config](06_Config.md) — read and update top-level settings stored in `config.yaml`.
- [vault](07_Vault.md) — connect team vaults, discover shared repositories, and publish projects and themes.
